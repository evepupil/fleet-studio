# fleet-studio 功能清单（第二版：多页看板）

> 最近更新：2026-09-25 · 状态：已定稿 · 上游：[需求设计 第九节](需求设计.md#九第二版多页看板) · 调研：[看板同类产品](调研/看板同类产品.md)

## 7 按优先级派活

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 7.1 | 点名只用点名的池 | 满了就在这个池排队 | 要 |
| 7.2 | 不点名按优先级挑 | 从第一位开始挑第一个有空位的池 | 要 |
| 7.3 | 满了顺延 | 往下顺延，停用的跳过 | 要 |
| 7.4 | 公共排队 | 全满时一起排队，哪个池先空出来给哪个，同时空出来按优先级 | 要 |
| 7.5 | 项目之间公平 | 公共排队里仍是占得少的项目先派 | 要 |
| 7.6 | 点名停用的池报错 | 写明是哪个池停用了 | 要 |
| 7.7 | 停用前的点名排队 | 继续等，重新启用后接着派 | 要 |
| 7.8 | 停用后不再派 | 公共排队里的任务不会派给停用的池 | 要 |
| 7.9 | 新池默认位置 | 排最后、默认启用 | 要 |
| 7.10 | 续接沿用原池 | 不重新挑；原池停用了就报错 | 要 |
| 7.11 | 显示最后派给了谁 | 任务列表和详情里写明所在池 | 要 |
| 7.12 | 命令行看优先级 | 查看池子时能看到优先级顺序和停用状态 | 要 |

## 10 数据保留与统计口径

| 编号 | 功能 | 一句说明 | 状态 |
|---|---|---|---|
| 10.1 | 记录永久保留 | 任务记录和过程时间线一直保留 | 要 |
| 10.2 | 原始输出按天清理 | 天数可配，默认 7 天 | 要 |
