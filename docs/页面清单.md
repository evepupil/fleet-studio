# fleet-studio 页面清单（第二版：多页看板）

> 最近更新：2026-09-25 · 状态：已定稿 · 上游：[功能清单](功能清单.md) · 下游：[前端设计](前端设计.md) · 布局参考：用户给的 Sub2API 控制台截图（左侧菜单 + 内容区顶栏 + 卡片行 + 筛选条 + 图表卡片网格）；示意图见 [前端设计 第 1 节](前端设计.md#1-方向与取舍)

控制台式布局：左侧菜单固定，右侧内容区顶上一条顶栏写页面名，下面是卡片和表格。编号写成「页面号.区块号」；括号里是对应的功能编号。

## 1 全站（每页都有）

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 1.1 | 左侧菜单 | 顶部产品名和版本号；总览、槽位、任务三项（图标 + 文字，当前页整行浅色底）；底部收起按钮（1.1、1.2） | 要 |
| 1.2 | 内容区顶栏 | 左边写页面名，不加副标题；右边放本页的一两个关键数（见各页） | 要 |
| 1.3 | 断线提示条 | 顶栏下方，自动重连（1.5） | 要 |
| 1.4 | 配置出错提示条 | 顶栏下方（1.7） | 要 |
| 1.5 | 连不上服务的整页提示 | 写明运行哪条命令把服务拉起来（1.10） | 要 |

## 2 总览

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 2.1 | 实时卡片行 | 槽位占用、工作中、排队中、重试中，点击跳转（3.1～3.4） | 要 |
| 2.2 | 时间筛选条 | 今日、近 7 天、近 30 天、全部、自选起止；只管下面的统计和图表（2.1、2.2） | 要 |
| 2.3 | 统计卡片行 | token 用量（拆输入 · 输出 · 缓存）、任务次数、总耗时、平均耗时，各带今日数（2.3～2.7） | 要 |
| 2.4 | token 分布 | 卡片头部切换模型、渠道、项目、角色；左边环形图，右边明细表（名称、任务数、token）；前 8 名加「其他」；点一行跳任务页（4.3～4.5、4.9） | 要 |
| 2.5 | 任务次数分布 | 按项目；左边环形图，右边明细表（项目、任务数、总耗时、token）；点一行跳任务页（4.6、4.9） | 要 |
| 2.6 | token 趋势 | 占满一行的折线图，一条线一种颜色，和 2.4 共用切换；悬停看数、点图例开关（4.1、4.2、4.7、4.8） | 要 |
| 2.7 | 没数据的提示 | 所选时间段内没有任务（1.8） | 要 |
