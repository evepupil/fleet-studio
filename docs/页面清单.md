# fleet-studio 页面清单（第三版：Linear 式工作台）

> 最近更新：2026-09-29 · 状态：已定稿 · 上游：[功能清单](功能清单.md) · 下游：[前端设计](前端设计.md) · 视觉依据：用户指定的设计提炼（`sonder-board/docs/设计提炼.md`，Linear 式看板）

浅灰窗口里：顶上 38px 窗口栏，左边 240px 侧栏，右下一块近白工作区；工作区顶上是 40px 视图栏和（任务页才有的）40px 筛选栏。编号写成「页面号.区块号」；括号里是对应的功能编号。第二版的页面清单（控制台三页）在 git 历史里。

## 1 全站（每页都有）

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 1.1 | 窗口栏 | 收起 / 展开侧栏；居中的「搜索任务」入口（Ctrl K）；右边槽位占用和排队数，点了去槽位页（12.1、12.9） | 要 |
| 1.2 | 侧栏 | 产品标记和版本；任务（带进行中数）、槽位、总览三项，当前项整行浅灰；「项目」分组，点项目看它的任务（1.1、12.2） | 要 |
| 1.3 | 手机侧栏 | 窗口 < 1024 时侧栏变成从左边滑出的抽屉（12.12） | 要 |
| 1.4 | 视图栏 | 每页的页名或面包屑，右边放本页的一两个控件（12.6） | 要 |
| 1.5 | 断线提示条 | 工作区顶部，自动重连（1.5） | 要 |
| 1.6 | 配置出错提示条 | 工作区顶部（1.7） | 要 |
| 1.7 | 连不上服务的整页提示 | 写明运行哪条命令把服务拉起来（1.10） | 要 |
| 1.8 | 搜索弹窗 | 按编号或标题找任务，回车直达详情；没输入时列最近的 8 个（12.9） | 要 |

## 2 任务 · 看板（首页）

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 2.1 | 视图栏 | 「任务」（选了项目时是「任务 › 项目」）；看板 / 列表切换；显示（12.6、12.8） | 要 |
| 2.2 | 筛选栏 | 筛选菜单（项目、池、角色）、已选条件小标签、清除筛选、标题搜索（12.7） | 要 |
| 2.3 | 三列 | 排队中、工作中、已完成，列头状态图标 + 名称 + 数量（12.3） | 要 |
| 2.4 | 收起组 | 失败、已取消两条短条带数量，失败数标红，点开展开成列、列头可收回（12.4） | 要 |
| 2.5 | 任务卡 | 编号 · 所在的池；状态图标 + 两行标题；进度小片、不通过、项目标签、角色标签（12.5） | 要 |
| 2.6 | 显示弹层 | 卡片上显示哪些信息：编号、池、项目、角色、进度（12.8） | 要 |
| 2.7 | 空和加载 | 骨架列；还没有任务；筛选无结果给「清除筛选」（1.8） | 要 |

## 3 任务 · 列表

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 3.1 | 视图栏、筛选栏 | 同 2.1、2.2，筛选菜单多一项状态，右边多一个时间范围（8.3～8.7、12.7） | 要 |
| 3.2 | 列表 | 状态图标、编号、标题（带排队位次 / 重试 / 失败原因 / 不通过标记）、项目、角色、池、用量、耗时、开始时间；窄屏逐档隐藏列（8.1、8.2、8.10、8.11、8.14～8.16） | 要 |
| 3.3 | 显示弹层 | 排序：开始时间、用量、耗时，降序 / 升序（8.8、8.9） | 要 |
| 3.4 | 尾部和空态 | 「共 N 个」；还没有任务；筛选无结果给「清除筛选」（8.13） | 要 |

## 4 任务 · 详情

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 4.1 | 视图栏 | 面包屑「任务 › 编号」（点「任务」返回，Esc 也返回）；复制编号（9.9、9.11） | 要 |
| 4.2 | 标题与状态 | 标题、状态、耗时、回报结论、第 N 次运行；失败或取消时写原因（9.2） | 要 |
| 4.3 | 回报 | 通过 / 不通过醒目标出（9.7） | 要 |
| 4.4 | 任务书 | 默认折叠（9.3） | 要 |
| 4.5 | 时间线 | 过程筛选、跟随滚动、「回到最新」、多次运行串一条（9.4～9.6、9.8） | 要 |
| 4.6 | 属性栏 | 右边 280px：状态、耗时、项目、角色、池、渠道、运行、用量、目录、创建；窄屏挪到标题下面（9.2、12.10） | 要 |
| 4.7 | 加载中、找不到、加载失败 | 骨架；「没有这个任务」+「回到任务」；「加载失败」+「重试」（1.8） | 要 |

## 5 槽位

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|

| 5.3 | 占用者提示卡 | 悬停格子：项目、标题、角色、已跑多久（5.4） | 要 |

| 5.5 | 改失败提示 | 说明原因，页面恢复原样（6.7） | 要 |
| 5.6 | 全部停用提醒 | 表格上方提示条 | 要 |

## 6 总览

| 编号 | 区块 | 放什么 | 状态 |
|---|---|---|---|
| 6.1 | 视图栏右侧 | 时间范围：今日、近 7 天、近 30 天、全部、自选（2.1、2.2） | 要 |
| 6.2 | 实时指标条 | 槽位占用（带占用条）、工作中、排队中、重试中，一条四格，点了跳转（3.1～3.4、12.11） | 要 |
| 6.3 | 统计指标条 | token 用量（拆输入 · 输出 · 缓存）、任务次数、总耗时、平均耗时，各带今日数（2.3～2.7、12.11） | 要 |
| 6.4 | token 分布 | 面板头部切换模型、渠道、项目、角色；环形图 + 明细表；点一行带筛选去列表（4.3～4.5、4.9） | 要 |
| 6.5 | 任务次数分布 | 按项目；环形图 + 明细表（4.6、4.9） | 要 |
| 6.6 | token 趋势 | 通栏折线图，标题旁写粒度，和 6.4 共用维度切换（4.1、4.2、4.7、4.8） | 要 |
| 6.7 | 没数据的提示 | 所选时间段内没有任务（1.8） | 要 |
