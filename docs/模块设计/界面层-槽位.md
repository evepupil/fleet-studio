# 界面层 · 槽位

> 模块定位：槽位页——按派活优先级列出每个「渠道 · 模型」的占用、战绩和今日用量，启停和上下移动调顺序 · 对应代码：`apps/web/src/features/slots/`、`apps/web/src/pages/SlotsPage.tsx` · 所属里程碑：[M6 第二版控制台看板](../roadmap.md#m6)、[M7 第三版界面](../roadmap.md#m7) · 状态：第三版已实现，待用户确认 · 最近更新：2026-09-29
>
> 视觉与交互规范：[前端设计](../前端设计.md)（第三版）；实现规格：[design/槽位.md](../../apps/web/design/槽位.md)；共用地基：[控制台框架](界面层-控制台框架.md)；服务端接口：[接口](服务层-接口.md) 第二版一节。

## 1. 职责与边界

- **管：** 快照里的池视图画成通栏表格（优先级、渠道模型、占用格子与提示卡、已用、点名排队、24 小时成功率、平均耗时、今日用量、启用开关、顺序按钮）；停用前确认；启停和排序请求；视图栏右侧公共排队数（点了带「排队中」去任务列表）；全部停用时的提示条。
- **不管：** 配置怎么写回、备份（服务端 `updateRaw`）；池的增删和容量（仍走配置文件或 fleet-ops）。

## 2. 结构与数据流

```text
SlotsPage ─▶ ViewBar(槽位, right = SharedQueuePill)
          ─▶ data-page-body（纵向滚动）
                ├─ AllDisabledNotice（全部停用时一条提示条）
                └─ SlotsTable（原生表格，最小 1120px，窄屏在自己的容器里横向滚动；snapshot.pools + 本地覆盖）
                      ├─ SlotsTableRow × N ─▶ SlotMeter（离散格 ≤ 24 / 连续分段条 > 24，提示卡，方向键移动焦点，回车打开任务详情）
                      └─ DisablePoolDialog（停用确认）
点开关 / 上下移动 ─▶ useSetPoolEnabled / useReorderPools ─▶ 成功：记本地覆盖，直到快照推来一致的数据；失败：清掉覆盖，钩子弹提示
```

## 3. 关键决策

| 决策 | 理由 |
|---|---|
| 第三版改成通栏表格，去掉外框卡片 | 设计提炼的列表是「只有细线分隔」的 Linear 式；工作区面板本身已经是一张卡 |
| 表格最小宽度 1120px | 除「渠道 · 模型」外九列定宽约 888px，留给它至少 230px；首轮截图在 1024 宽时它只剩 92px |
| 请求成功后用本地覆盖顶住，直到快照追上 | 避免成功后、新快照到之前开关闪回旧值 |
| 停用要确认，启用不用 | 停用会让点名的任务一直排队，代价大 |
| 今日用量只显示合计，悬停看输入输出缓存 | 第二版首轮截图里拆成三行把行撑高 |
