# 界面层 · 总览

> 模块定位：总览页——实时卡片、时间筛选、统计卡片、token 分布、任务次数分布、token 趋势 · 对应代码：`apps/web/src/features/overview/`、`apps/web/src/pages/OverviewPage.tsx` · 所属里程碑：[M6 第二版控制台看板](../roadmap.md#m6) · 状态：已实现，待用户确认 · 最近更新：2026-09-25
>
> 视觉与交互规范：[前端设计](../前端设计.md)；实现规格：[design/总览.md](../../apps/web/design/总览.md)；共用地基：[控制台框架](界面层-控制台框架.md)。

## 1. 职责与边界

- **管：** 把快照里的实时数（`live`、`sharedQueued`）画成四张可点的卡片；把 `GET /api/stats` 的结果画成统计卡片、两张「环形图 + 明细表」和一张折线图；点卡片或明细行时带着筛选跳到任务页。
- **不管：** 统计口径（全部由服务端 `computeStats` 算好）；任务页怎么筛（只调 `taskFilterStore.applyFromOverview`）。

## 2. 结构与数据流

```text
OverviewPage ─▶ LiveCards（snapshotStore）
             ─▶ RangeBar（overviewStore.range，显示返回的粒度）
             ─▶ StatCards ┐
             ─▶ StatsBody ┴─ 共用 useStats(overviewStatsQuery(state))，同一个查询键只发一次请求
                   ├─ 没数据：合并成一张「这段时间没有任务」
                   ├─ 出错：一张 ErrorState
                   └─ TokenShareCard + TasksByProjectCard（并排等高）、TokenTrendCard（通栏）
维度切换（overviewStore.dimension）同时作用于 token 分布和 token 趋势
```

## 3. 关键决策

| 决策 | 理由 |
|---|---|
| 分布用「环形图 + 明细表」 | 用户给的 Sub2API 布局参考；环形图看占比，表给准确数字，读屏也靠表 |
| 明细表用固定布局，数字列定宽、名称拿剩余宽度 | 首轮截图名称被截成「deep…」 |
| 趋势线每个点画实心点 | 用户要「点状连起来的折线图」 |
| 选「今日」时不显示「今日 …」补充行 | 和大数字重复 |
| 切换档位保留旧数据（keepPreviousData） | 不闪空 |

## 4. 当前实现

- 总览一路（luna）按页面规格实现 O1～O6；首轮截图验收后修复路改了：占用条填充不显示（改用行内宽度样式）、明细表名称列太窄、两张分布卡不等高、趋势线没有数据点且线上有缺口（点改为线色实心、面板色描边）。
- 交互检查覆盖：实时卡片数字与跳转、今日档位、维度切换、明细行跳转带小标签、分布不足 9 项时没有「其他」、图例开关、空场景、停用场景。
