# fleet-studio 前端设计

> **一句话视觉方向：** Linear 式浅色工作台。浅灰窗口 → 近白工作区 → 淡灰看板列 → 白卡片，四层只差一点明度；1px 低对比细线加很浅的阴影；13 号正文、12 号辅助字，字重只有 400 和 500；颜色只用来识别（团队绿、工作中黄、已完成紫、失败红、彩色项目标签），背景和正文保持中性；选中只靠一整行浅灰，不靠加粗和大标题。深色是同一套层级的暗色版本，跟随系统。
>
> **参考来源：** 用户指定的设计提炼 `C:/code/shadcn-studio/sonder-board/docs/设计提炼.md`（一张 Linear 式看板截图的提炼：38px 窗口栏、240px 侧栏只给当前入口整行浅灰、40px 视图栏和筛选栏、三列展开加已结束状态收成短行、三层任务卡、13/17 与 12/16 字阶、卡片 6 控件 5 的圆角、1.7px 图标描边、不加大标题和统计卡）——第三版唯一的视觉依据。Linear 桌面版（凭记忆）只借组件形态：筛选下拉带二级菜单、已选条件小标签、「显示」弹层、Ctrl K 搜索、详情页左正文右属性栏、Linear 式状态图标。第一、二版的参考（Linear 侧栏、HashiCorp Nomad、Temporal、Grafana、Vercel、Sub2API 控制台）见第 1 节历史和 [参考界面](调研/参考界面.md)、[看板同类产品](调研/看板同类产品.md)。
>
> **对应代码：** `apps/web/` · 令牌文件 `apps/web/src/styles/tokens.css` · 类名映射 `apps/web/src/styles/globals.css` · 实现规格 `apps/web/DESIGN.md`、`apps/web/design/*.md`
>
> **当前状态：** 第三版（[M7](roadmap.md#m7)）规格定稿、实现中；第二版（控制台三页）已实现并在本机使用 · 最近更新：2026-09-29

## 1. 方向与取舍

第三版由用户直接指定方向：把看板重构成设计提炼描述的 Linear 式工作台，没有再出多个视觉方向挑选。落到本项目时和用户定了四件事：

| 取舍 | 定下来的做法 |
|---|---|
| 看板展开哪三列 | 排队中、工作中、已完成展开；失败、已取消收在右侧短条，失败数标红，点开可展开成列 |
| 深色主题 | 保留跟随系统，按浅色的四层明度推一版深色 |
| 首页 | 打开就是任务看板；侧栏顺序改成任务、槽位、总览；`fleet open` 也打开看板 |
| 总览 | 去掉大数字统计卡，改成紧凑的指标条（数字 16px 中等字重），图表放进细边框面板 |

另外：设计提炼里的新建、编辑弹窗不搬（看板仍然只读，写操作只有槽位启停和排序）；没有头像和优先级，卡片「负责人」位置放所在的池，「优先级」位置放进度小片（排队位次 / 已跑时长 / 重试 / 失败原因）。

历史：

| 版本 | 方向 | 结论 |
|---|---|---|
| 第一版 | 三个方向挑一：A 暗色仪表板（[示意图](前端设计/示意图/01-方向A-暗色仪表.png)）、B 浅色纸面（[示意图](前端设计/示意图/01-方向B-纸面浅色.png)）、C 石墨琥珀（[示意图](前端设计/示意图/01-方向C-石墨琥珀.png)） | A 为默认、B 为浅色主题；C 因琥珀色同时表示状态和项目而弃用 |
| 第二版 | 控制台布局，按用户给的 Sub2API 截图排版，两版配色：A 克制（[示意图](前端设计/示意图/02-控制台-总览-A克制.png)）、B 参考配色 | 采用 A；铺开的页面示意图：[槽位](前端设计/示意图/03-控制台-槽位-A.png)、[任务](前端设计/示意图/04-控制台-任务-A.png)、[任务详情](前端设计/示意图/05-控制台-任务详情-A.png) |

## 2. 信息结构

| 页面 | 地址 | 回答的问题 |
|---|---|---|
| 任务 · 看板（首页） | `#/tasks` | 谁在排队、谁在干活、刚做完什么、哪些失败了（数据是实时快照：进行中 + 最近 24 小时结束的） |
| 任务 · 列表 | `#/tasks/list` | 更早的历史：按状态、项目、池、角色、时间筛，按开始时间、用量、耗时排 |
| 任务 · 详情 | `#/tasks/<编号>` | 这个任务是谁在做、做到哪、任务书是什么、过程里发生了什么、交回了什么 |
| 槽位 | `#/slots` | 每个池被谁占着、排了几个、最近顺不顺；停用、调派活顺序 |
| 总览 | `#/overview` | 现在忙不忙；选定时间段里 token 花在哪、派了多少活 |

骨架（每页都有）：

| 区域 | 放什么 |
|---|---|
| 窗口栏（38px，浅灰） | 左：收起 / 展开侧栏；中：搜索任务（Ctrl K）；右：槽位占用「槽位 23/40 · 排队 7」，点了去槽位页 |
| 侧栏（240px，浅灰） | 产品标记（绿色方块）+ fleet studio + 版本；主菜单：任务（右侧进行中数）、槽位、总览；「项目」分组：每个项目的色点、名字、进行中数，点了看这个项目的任务 |
| 工作区（近白面板，1px 细线，圆角 6） | 视图栏（40px：页名或面包屑、看板 / 列表切换、显示）→ 筛选栏（40px，只有任务页：筛选菜单、已选条件、时间、标题搜索）→ 内容 |

看板：三列（排队中、工作中、已完成）平分宽度，每列一条淡灰托盘，列头「状态图标 + 名称 + 数量」；右侧 200px 的收起组放失败、已取消两条短条。任务卡三层：① 编号 · 所在的池；② 状态图标 + 标题（最多两行）；③ 进度小片 + 不通过 + 项目标签 + 角色标签。列内顺序：排队中按排队位次，工作中最近开跑的在前，已结束最近结束的在前。

**故意不做：** 新建、编辑、取消任务等写操作（除槽位启停和排序）；拖拽卡片；头像；页面副标题和说明文字；主题切换按钮（跟随系统）；大号数字统计卡；任何入场动画。

### 3.2 强调色与团队色

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#3F5FD6` | `#7F9CFF` | 只用于：焦点环、开关打开、链接式按钮文字、主按钮（「回到最新」）、日历选中日（做文字时浅色 ≥ 4.87） |
| `--accent-soft` | `rgba(63,95,214,0.10)` | `rgba(127,156,255,0.16)` | 文字选中底、日历范围中段 |
| `--on-accent` | `#FFFFFF` | `#0F0F11` | 强调色、团队色、失败色上的文字 |
| `--team` | `#2E9D5B` | `#3DB070` | 侧栏产品标记（「绿色团队」），别处不用 |

选中态一律用 `--bg-selected` 浅灰，不用强调色——这是和第二版最大的区别。

### 3.3 状态色与状态图标

图标是内联图形（Linear 式），静止不转；状态词一律中性文字色，颜色只落在图标上。

| 令牌 | 浅色 | 深色 | 状态 | 图标形状 |
|---|---|---|---|---|
| `--st-queued` | `#8B8D96` | `#8E8F98` | 排队中 | 虚线圈 |
| `--st-running` | `#D9A300` | `#E8B400` | 工作中 | 圈 + 右半填充 |
| `--st-warning` | `#A95500` | `#F0893A` | 重试中、提示条图标 | lucide `RotateCw` / `TriangleAlert` |
| `--st-done` | `#7652D6` | `#A58CF7` | 已完成、回报通过 | 实心圆 + 勾 |
| `--st-failed` | `#C8372F` | `#F2675E` | 失败、不通过、超出容量 | 实心圆 + 叉 |
| `--st-cancelled` | `#8F919A` | `#76777F` | 已取消 | 圈 + 斜杠 |
| `--st-warning-soft` / `--st-failed-soft` | 8% / 7% | 12% / 10% | 提示条、异常时间线行、失败说明的淡底 | — |

可做文字的只有 warning、done、failed（浅色在卡片、面板、列底上 ≥ 4.60）。running（浅色 2.29）、queued、cancelled 只做图形：状态靠形状和列名、状态词表达，颜色只是辅助；工作中黄色为了像设计提炼那样明亮，接受图形对比度低于 3:1。

| `--font-mono` | `"Cascadia Mono", "JetBrains Mono", Consolas, "Microsoft YaHei UI", monospace` |

| 类名 | 字号 / 行高 | 用在哪 |
|---|---|---|
| `text-12` | 12 / 16 | 辅助：编号、时间、计数、标签、表头、分组标题、按钮和输入框文字 |
| `text-13` | 13 / 17 | 正文：卡片标题、列表标题、菜单项、属性值、时间线正文 |

### 3.6 间距、圆角、阴影、层级、图标

- 间距阶梯（4px 基准）：4、8、12、16、20、24、32。卡片之间、列之间 8px；列和卡片内边距 8 / 12px；页面内容区 16px。
- 圆角：`--r-chip` 4px（标签、小片、按键提示）、`--r-control` 5px（按钮、输入框、菜单项、侧栏行、视图切换）、`--r-card` 6px（卡片、看板列、面板、工作区、弹层、弹窗）、`--r-slot` 2px（占用格）。
- 阴影：`--shadow-card` 浅 `0 1px 2px rgba(20,21,26,0.05)`、深 `0 1px 2px rgba(0,0,0,0.3)`；`--shadow-panel` 浅 `0 1px 3px rgba(20,21,26,0.04)`、深无；`--shadow-overlay` 浅 `0 8px 24px rgba(20,21,26,0.10), 0 0 0 1px #E5E5E8`、深 `0 8px 24px rgba(0,0,0,0.5), 0 0 0 1px #2A2A2E`。
- 层级：`--z-sticky` 10（表头、时间线头部）、`--z-banner` 20（提示条）、`--z-overlay` 30（菜单、弹层、提示卡、弹窗、抽屉）。
- 图标：lucide 细线图标，全站描边 `--icon-stroke` 1.7；常用 14px（控件里）和 16px（侧栏、视图栏）。

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--dur-fast` | 120ms | 悬停底色、描边 |

## 4. 布局与响应式

| 宽度 | 结构 |
|---|---|
| ≥ 1280 | 侧栏 240 常驻；看板三列平分 + 收起组 200，一屏放下；总览两张环形图并排；列表九列全显示；详情左正文（最宽 800 居中）右属性栏 280 |
| 1024–1279 | 同上，但看板列到 248 下限后在看板内部横向滚动；总览图表单列；列表隐藏角色列 |
| 800–1023 | 侧栏变成从左边滑出的抽屉（窗口栏按钮打开）；详情属性栏挪到标题下面；列表再隐藏池和用量 |
| < 800 | 手机：搜索入口缩成图标；看板每列 280 并按列吸附横向滑动；列表只剩状态、标题、开始时间；筛选栏整条横向滚动；槽位表格在自己里面横向滚动；总览时间范围换成下拉框 |

- 页面整体从不横向滚动；窗口和工作区不滚动，滚动交给每页的内容区（看板的列、列表、详情左右两栏、总览和槽位的内容区）。
- 工作区离窗口右边和下边 8px（手机 4px），侧栏隐藏时左边也留同样的边。
- 验收宽度：1440、1280、1024、800、390。

| 表格 / 列表行 | 透明、下边 1px `--line` | `--bg-hover` | 键盘聚焦内描边焦点环 | 停用的池：文字 `--text-3`、格子 0.4 | 骨架行 | — |
| 指标格 | `--bg-card`，格间 1px 细线 | 可点的格 `--bg-raised` | — | — | 数字换成 80×22 骨架 | 数字写「—」 |
| 弹窗 / 弹层 | `--bg-overlay`、圆角 6、`--shadow-overlay` | — | — | — | — | 框内写错误原因 |

焦点环：所有可聚焦元素 `outline: 2px solid var(--accent); outline-offset: 2px`，只在键盘聚焦时出现。

## 6. 空态、加载态、错误态

统一画法：区域中央一段 `--text-2` 的短句，前面可以有一个 16px 的 `--text-3` 图标，后面最多一行等宽命令或一个文字按钮；不配插图。加载一律静止骨架（`--bg-hover` 块，形状对齐真实内容）。

| 场景 | 画法 |
|---|---|
| 首次打开，快照还没到 | 看板画 3 列列壳 + 骨架卡；侧栏的进行中数和项目分组不显示；窗口栏不显示占用数 |
| 一个任务都没有 | 看板和列表居中：「还没有任务」+ `fleet run "任务"` |
| 筛选后没有结果 | 「没有符合条件的任务」+「清除筛选」 |
| 看板某列为空 | 只有列头（数量 0），列身空白 |
| 详情加载中 / 找不到 / 失败 | 标题、回报、时间线、属性的骨架 /「没有这个任务」+「回到任务」/「加载失败：原因」+「重试」 |
| 时间线还没有事件 | 排队中「排队第 N 位」、工作中「等待第一条输出」、其余「没有输出」 |
| 搜索没有结果 / 失败 | 「没有找到任务」/「搜索失败：原因」 |
| 连接断开 | 工作区顶部 32px 提示条「连接已断开，正在重连」，内容整体 60% 不透明 |
| 配置文件有错 | 同样的提示条「配置文件有错，正在使用上一份有效配置：原因」 |
| 所有池都停用 | 槽位页表格上方提示条「所有池都已停用，没点名的任务派不出去」 |
| 所选时间段没有任务 | 总览图表区一块面板「这段时间没有任务」 |
| 第一次就连不上服务 | 工作区中央「连不上 fleet 服务」+ `fleet daemon start` +「重试」 |
| 长文本 | 卡片标题两行省略；列表标题单行省略、悬停看全文；标签单行省略；路径中间省略 |

## 7. 无障碍底线

- 正文对比度 ≥ 4.5:1（第 3 节已逐个核实）；浅色 `--text-3` 不放在选中底上。
- 键盘可达：侧栏、视图切换、筛选、卡片、列表行都能 Tab 到；看板卡片之间用方向键移动（上下同列、左右换列）；列表行上下键移动；回车打开；Esc 从详情页返回、关闭弹窗和菜单；Ctrl K 打开搜索，搜索结果上下键选、回车打开。
- 状态从不只靠颜色：看板有列名，列表和卡片的状态图标形状不同且带无障碍名称；重试格有斜纹；项目身份有名字。
- 侧栏是 `nav`，当前项 `aria-current="page"`；启用开关 `role="switch"` 带名称「启用 dsf」；搜索框是 `combobox` 配 `listbox`；时间线是 `role="log"`。
- 减少动态效果时关掉仅有的两处转圈。

## 8. 文案

遵循全局界面文案守则：删掉不影响理解的字就不写。

- 状态：排队中、工作中、已完成、失败、已取消；附加：重试 N/M、排队第 N 位、公共排队第 N 位、不通过。
- 骨架：任务、槽位、总览、项目、搜索任务、Ctrl K、槽位 23/40 · 排队 7、收起侧栏、展开侧栏。
- 任务页：看板、列表、筛选、显示、清除筛选、搜索标题、卡片显示（编号、池、项目、角色、进度）、排序（开始时间、用量、耗时，降序、升序）；详情：任务 › 编号、复制编号、回报、任务书、时间线；属性：状态、耗时、项目、角色、池、渠道、运行、用量、目录、创建。
- 槽位和总览的表头、指标名沿用第二版。
- 时长：45秒、3分12秒、1时05分。时间：`12:03:04`，非今天加日期 `09-22 12:03`。

## 9. 落地方式

- **令牌：** `apps/web/src/styles/tokens.css` 用 CSS 变量定义全部令牌：`:root` 放浅色值，`@media (prefers-color-scheme: dark)` 里的 `:root` 放深色值。这是唯一允许出现色值的文件。
- **类名映射：** `apps/web/src/styles/globals.css` 的 `@theme inline` 把令牌映射成 Tailwind 类名（`bg-window`、`bg-panel`、`bg-column`、`bg-card`、`bg-raised`、`bg-overlay`、`bg-hover`、`bg-selected`、`border-line`、`text-fg-1～3`、`text-brand`、`bg-team`、`text-status-*`、`proj-*`、`series-*`、`text-12～16`、`rounded-sm/md/lg`、`shadow-card/panel/overlay`），shadcn/ui 读的那组变量（背景、卡片、弹出层、主色、边框、焦点环、图表色）也在这里映射成本项目令牌的别名。全站图标描边在这里统一成 1.7。
- **组件：** shadcn/ui 源码在 `apps/web/src/components/ui/`，只通过令牌和变体调外观；业务共享组件（状态图标、标签、视图栏、筛选栏、视图切换、面板、指标条等）在 `apps/web/src/components/`；各页业务组件在 `apps/web/src/features/`。
- **门禁：** `scripts/check-tokens.mjs` 拦截写死的色值、Tailwind 自带调色板、方括号里的色值、停用的字号字重和旧类名。
