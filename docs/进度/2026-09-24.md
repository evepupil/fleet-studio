验收中发现并派修的问题：

| 问题 | 严重程度 | 去向 |
|---|---|---|
| `fleet run --wait` / `fleet send --wait` 每次退出都触发 Node 底层断言，退出码变 127 | 严重 | fleet 命令路 |
| 苦工跑超过 30 秒时 `fleet wait` 必然失败：命令行统一 30 秒超时，而等待接口按设计要挂住最多 60 秒 | 严重 | fleet 命令路 |
| 等待超时什么都不打印；`fleet show` 看不到失败原因；参数报错透出英文；已结束苦工按编号排序；费用为 0 也显示；时长秒数不补零 | 一般 | fleet 命令路 |
