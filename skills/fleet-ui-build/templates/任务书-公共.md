【实现纪律】

- 严格照页面层规格写：**那里写了的元素一个都不能少**，写了的类名、数值、文案照抄；没写的细节按同一套令牌补齐，风格不要跑偏（<一句话概括本项目风格>）。
- 用到状态、副作用或事件处理的文件第一行必须是客户端指令；纯展示的不要加。服务端组件可以直接渲染带客户端指令的共享组件，但**不能把函数当参数传给它**——需要回调的区块自己就得是客户端组件。
- 所有业务数字、时间、名额都从数据文件取，**组件里不写死**；显示格式一律用格式化函数。
- Tailwind 只认完整类名：按状态切换颜色用对象映射完整类名，**禁止**拼接类名。组件里不写十六进制色值（规格注明的例外除外）。
- TypeScript strict：禁止 any、禁止忽略类型错误、禁止未使用的 import 或变量。
- <按项目补：转义、随机数、取当前时间、断点判断、定时器清理等易错项>
- 桌面 <宽度> 和移动 <宽度> 都要完整可看，移动端禁止横向溢出。
- **布局守则**（这几条截图才抓得到，规格没写也要做到）：
  · 宽表格、宽图放进横向滚动容器；这个容器如果包在网格子项里，给那个子项加 `min-w-0`；
  · 纵向弹性布局里的小徽标、小标签加 `self-start`，不要被拉成整条；
  · 左右两栏卡片高度不一，规格没写等高就给短的那栏加 `lg:self-start`；
  · 能用键盘聚焦的 SVG 元素要有可见的焦点样式；
  · 长文本用 `truncate` / `break-words` / `line-clamp-*` 兜住。
- 所有图片带 alt；图标按钮有 aria-label；SVG 图有 role 与 aria-label，纯装饰的加 aria-hidden；所有可交互元素有可见焦点态。
- 区块组件同时提供具名导出和默认导出，不接收参数（规格里注明的例外除外），自带最外层容器。
- 规格里标了 `data-*`、`id`、`aria-label`、按钮文字的地方**一字不改**，交互检查要用。
- 关键交互处写一两句中文注释说明原理。
