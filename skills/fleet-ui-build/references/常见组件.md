# 常见组件

写页面规格选组件时，先看这里有没有现成的，别自造。

| 类别 | 组件 | 适合 |
|---|---|---|
| 导航 | 面包屑 | 有层级的深页 |
| | 标签页 | 同一对象的几组内容切换 |
| | 树形目录 | 有层级的文档、分类 |
| | 侧栏菜单 | 后台入口 |
| | 锚点目录 | 长文内跳转 |
| | 分页 | 结果超过一屏，且要能分享某一页 |
| 展示 | 表格 | 参数多、要横着比 |
| | 卡片 | 以图为主、条目少 |
| | 键值表 | 单个对象的属性 |
| | 标签 / 徽章 | 状态、分类的小标记 |
| | 空状态 | 没数据时告诉人怎么开始 |
| | 骨架屏（加载时先画出灰色轮廓） | 加载中占位 |
| 筛选输入 | 搜索框 | 文字查找 |
| | 多选勾选 | 枚举、多值 |
| | 单选 / 分段控件 | 两三个互斥选项，例如公制 / 英制 |
| | 范围滑块 + 数字框 | 数值区间，滑块粗调、数字框精调 |
| | 开关 | 是 / 否 |
| | 下拉 | 选项多、占地小 |
| | 已选条件条 | 显示当前筛选，可以逐个删 |
| 反馈 | 弹层 | 要打断用户的确认 |
| | 抽屉（从侧边滑出的面板） | 不离开当前页看详情 |
| | 气泡 / 悬浮提示 | 解释一个词、一个数的出处 |
| | 提示条 | 结果为空、操作成功 |
| 动作 | 按钮 | 主动作一个页面只放一个 |
| | 图标按钮 | 次要动作 |
| | 勾选框 | 多选后对比、批量操作 |
| | 下拉菜单 | 一堆次要动作 |
