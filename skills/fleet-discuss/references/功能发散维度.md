# 功能发散维度

列功能清单前，逐个维度过一遍：这类产品在这个维度上，正常该有什么。想得到就列，拿不准也列，由用户删；和这个产品确实不相干的维度直接跳过，不用写出来。

| 维度 | 常见功能（举例） |
|---|---|
| 账号与身份 | 注册、登录、退出、找回密码、第三方登录、双重验证、登录设备管理、注销账号 |
| 权限与组织 | 管理员与普通用户、团队或组织、成员邀请、角色权限 |
| 合规与协议 | 用户协议、隐私政策、数据处理与保留期限、Cookie 提示、未成年人保护、备案信息（在国内上线） |
| 核心业务 | 按产品类型列：主流程的每一步、主要对象的新建查看修改删除、导入导出 |
| 收费 | 定价方案、套餐、余额与充值、按量计费、订单与账单、发票、退款、优惠码 |
| 用户自己的数据 | 用量统计、历史记录、数据导出、删除自己的数据 |
| 通知 | 站内消息、邮件、短信、公告、异常提醒 |
| 运营 | 新手引导、帮助中心、常见问题、客服与反馈、工单、邀请与推广、活动 |
| 管理后台 | 用户管理、内容管理、配置管理、订单管理、日志查看 |
| 安全与风控 | 限流、防刷、异常检测、密钥管理、PII 检测（识别个人信息）、DLP（防止敏感数据外泄）、内容审核 |
| 审计与日志 | 管理员操作审计、调用日志、错误记录 |
| 稳定与监控 | 健康检查、状态页、告警、故障转移、备份与恢复 |
| 开发者接入 | API（给别的程序调用的接口）、API 密钥、开发文档、SDK（现成的调用代码库）、Webhook（出事时主动通知对方）、在线调试 |
| 体验 | 搜索、筛选与排序、多语言、深浅主题、手机端适配、快捷键、无障碍 |
| 个人工具常见 | 本机存数据、离线可用、导入导出与备份、多设备同步、快捷操作 |

## 用户的口语目标怎么翻

| 用户说 | 对应要列的维度 |
|---|---|
| 要赚钱 | 收费一整组，再加订单、发票、退款 |
| 看起来正规 | 合规与协议、客服与反馈、状态页、公告 |
| 给别人用 | 账号与身份、权限与组织、通知、管理后台 |
| 数据要安全 | 安全与风控、审计与日志、备份与恢复 |
| 自己用 | 个人工具常见那一行；账号、收费照样列上，写明「自己用可以不要」，由用户删 |
