# 常见区块

列页面里的区块时的查漏表，按页面类型分：照着过一遍，拿不准的也列上，由用户删。右边两列是给你写推荐时参考的。

## 全站

| 区块 | 一般什么时候要 | 一般什么时候不要 |
|---|---|---|
| 顶栏 | 总要 | |
| 页脚 | 总要 | |
| 侧栏导航 | 后台，入口四个以上 | 入口少，顶栏够 |
| 面包屑（「首页 > 分类 > 当前页」这种路径） | 层级三层以上、搜索引擎会直接落到深页 | 扁平站 |
| 公告条 | 有要广播的事 | 平时不放 |
| 悬浮条（对比栏、购物车条） | 几乎不要，动作放在对象旁边 | |

## 首页 / 落地页

| 区块 | 一般什么时候要 | 一般什么时候不要 |
|---|---|---|
| 首屏大标题区 | 总要 | |
| 信任背书 | 有真实客户、数字 | 没有 |
| 功能网格 | 三个以上功能 | 单一功能，一张截图加一段话 |
| 截图 / 演示 | 有界面 | 还没界面 |
| 使用流程三步 | 用起来有流程 | 打开就用 |
| 对比表 | 有明确竞品 | 无 |
| 定价 | 定价简单 | 另有定价页 |
| 常见问题 | 真被问过的问题 | 编的 |
| 行动号召横幅 | 页面长，首屏已滚出视野 | 页面短 |

| 区块 | 一般什么时候要 | 一般什么时候不要 |
|---|---|---|
| 页头一行 | 说清这是什么、有多少 | |
| 筛选栏 | 参数多、要缩小范围 | 条目少于一屏 |
| 已选条件 | 有筛选栏就要 | |
| 搜索框 | 顶栏没有 | 顶栏已有 |
| 排序 | 有可排序的字段 | 顺序天然 |

## 两条摆放规矩

- 动作跟着对象走：对比、收藏、导出放在有对象的地方（列表行、详情页的操作区），不进顶栏，不做悬浮条。
- 顶栏只放「去别处」：用户什么都没做时点进去是空页面的入口，不该在顶栏。
