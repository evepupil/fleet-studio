# 常见页面

列页面清单时的查漏表：照着过一遍，拿不准的也列上，由用户删。右边两列是给你写推荐时参考的。

| 页面 | 一般什么时候要 | 一般什么时候不要 |
|---|---|---|
| 首页 / 落地页 | 对外产品，要说服人 | 工具站、资料站，直接落到主功能页 |
| 定价 | 收费产品 | 免费、内部、报价靠谈 |
| 功能 / 产品页 | 功能多到首页放不下 | 单一功能，首页够 |
| 案例 / 客户 | 有真实客户 | 没有，编的更糟 |
| 关于 | 需要交代谁做的、立场 | 一段话放页脚够 |
| 博客 / 更新日志 | 有人持续写 | 没人写，空的比没有糟 |
| 联系 / 预约 | 靠人跟进的销售 | 自助注册 |
| 文档 | 有 API、有集成、有配置 | 打开就会用 |
| 登录 / 注册 | 有账号体系 | 无 |
| 找回密码 | 有密码 | 只用第三方登录 |
| 新手引导 | 第一次进来不知道干嘛 | 空状态一句提示够 |
| 总览 | 多种东西要一起看个大概 | 只有一种，直接列表 |
| 列表 | 有一堆同类东西要找 | 无 |
| 详情 | 单个东西信息多到列表放不下 | 列表一行能看完 |
| 新建 / 编辑 | 字段多 | 字段少，弹窗或行内改 |
| 设置 | 有可改的偏好 | 无 |
| 账单 | 收费 | 免费 |
| 搜索结果 | 搜索结果和列表长得不一样 | 搜索就是列表加一个条件 |
| 对比 | 用户要并排看多个 | 无 |
| 分类 / 标签页 | 分类有自己的内容 | 只是列表加一个固定条件 |
| 作者页 | 多作者 | 单作者 |
| 404 | 总要 | |
| 出错 / 维护中 | 总要 | |
| 隐私 / 条款 | 法律要求 | 页脚放链接即可 |
