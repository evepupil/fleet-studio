# 任务 · 视图栏、筛选栏、显示弹层、列表 `#/tasks`、`#/tasks/list` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 本路负责任务页的外壳（视图栏、筛选栏、显示弹层，看板和列表共用）和列表视图。看板本体 `TaskBoard` 由看板路写，本路只在页面里 import 它。

本页节奏：工作区 `bg-panel` 上：40px 视图栏（下边 1px 细线）→ 40px 筛选栏（下边 1px 细线）→ 内容区（看板：淡灰列托盘 + 白卡片；列表：近白底上的一行行细线分隔）。
本页核心动作：切看板 / 列表、筛选、搜标题、点一行进详情。
本页最重要的区块：T2 筛选栏（两种视图都靠它）和 T5 列表。

旧文件处理：`features/tasks/` 下的 `TaskFilterBar.tsx`、`TaskTable.tsx`、`TaskTableRow.tsx`、`TaskTableLoading.tsx` 按本规格重写或改名（列表改名为 `TaskList*.tsx`，旧的 `TaskTable*.tsx` 删掉）。本目录可以新建的文件：`TaskFilterBar*.tsx`、`DisplayMenu*.tsx`、`TaskList*.tsx`。

## T2 筛选栏 `features/tasks/TaskFilterBar.tsx`

**签名**：`export function TaskFilterBar({ view }: { view: TaskView })`。

**外层**：`<FilterBar>`（共享组件，40px、下边细线、< 800 时整条可横向滚动）。

**元素**（从左到右，全部受控，值读写 `taskFilterStore`）：

1. **筛选菜单**（子组件 `TaskFilterBarMenu.tsx`）：shadcn `DropdownMenu`。
   - 触发：`<Button variant="ghost" data-filter-trigger className="shrink-0"><ListFilter aria-hidden="true" />筛选</Button>`。
   - 内容 `<DropdownMenuContent data-filter-menu align="start">`，四个二级菜单，每个是 `DropdownMenuSub`：`DropdownMenuSubTrigger`（带 `data-filter-field={字段}`）+ `DropdownMenuSubContent className="max-h-[320px] overflow-y-auto"` 里一个 `DropdownMenuRadioGroup`：

| 字段 | 二级菜单文字 | 只在哪个视图 | 选项（第一项是「不筛」） | 选项标记 |
|---|---|---|---|---|
| `status` | 状态 | 列表 | `TASK_STATUS_OPTIONS` 全部八项（全部、进行中、排队中、工作中、重试中、已完成、失败、已取消），值就是它们的 `value` | `data-filter-option="status:{value}"` |
| `project` | 项目 | 两种都有 | 「全部项目」（值 `__all__`）+ 项目：`useProjects()` 的结果，再并上快照 `projects` 里它没有的，按名字排序；每项 `ColorDot`（8px）+ 名字（单行省略，`max-w-[220px]`） | `data-filter-option="project:{key}"`，全部项目是 `project:__all__` |
| `pool` | 池 | 两种都有 | 「全部池」（`__all__`）+ `snapshot.pools`（按优先级）：`font-mono` 池编号 + 空格 + `text-fg-3` 显示名 | `data-filter-option="pool:{id}"` / `pool:__all__` |
| `role` | 角色 | 两种都有 | 「全部角色」（`__all__`）+ `snapshot.roles`：中文名 | `data-filter-option="role:{id}"` / `role:__all__` |

   - 选中一项：写回仓库（`__all__` 写成 `undefined`；状态直接写 `value`），菜单关闭（Radix 默认行为）。当前值对应的选项显示勾。
   - 快照没到时池、角色二级菜单只有「全部 X」一项；项目加载中或出错时只有「全部项目」。
2. **已选条件**：`<div data-active-filters className="flex min-w-0 flex-1 items-center gap-1.5 overflow-x-auto">`：
   - 每个 `activeFilterChips(filters, lookups, view)` 的结果一个小标签：
     ```tsx
     <span data-chip={chip.key} className="inline-flex h-6 shrink-0 items-center gap-1 rounded-md border border-line bg-card pl-2 pr-0.5 text-12 text-fg-1 shadow-card">
       <span className="max-w-[200px] truncate" title={chip.label}>{chip.label}</span>
       <button type="button" aria-label={`去掉 ${chip.label}`} className="grid size-5 place-items-center rounded-sm text-fg-3 transition-colors hover:bg-hover hover:text-fg-1" onClick={() => set(chipResetPatch(chip.key))}>
         <X aria-hidden="true" className="size-3" />
       </button>
     </span>
     ```
   - `lookups`：`projects` = 项目 key → 名字（同上的合并结果）；`pools` = 池编号 → 池编号；`roles` = 角色编号 → 中文名；`channels`、`models` 不传（直接显示原值）。
   - `hasActiveFilters(filters, view)` 为 true 时，最后跟一个 `<Button variant="link" size="sm" data-clear-filters className="shrink-0" onClick={reset}>清除筛选</Button>`。
3. **时间范围**（只在列表视图）：`<div data-filter="range" className="shrink-0"><RangePicker variant="select" name="tasks-range" value={filters.range} onChange={(range) => set({ range })} /></div>`。
4. **标题搜索**（子组件 `TaskFilterBarSearch.tsx`，两种视图都有）：`<div className="relative w-[200px] shrink-0 max-md:w-[140px]">`
   - 左侧 `Search` 14px（`pointer-events-none absolute left-2 top-1/2 -translate-y-1/2 text-fg-3`，`aria-hidden`）；
   - `<Input data-filter="q" aria-label="搜索标题" placeholder="搜索标题" value={draft} className="pl-7 pr-7" …/>`；
   - 有字时右侧清空按钮 `<button type="button" aria-label="清空搜索" className="absolute right-1 top-1/2 grid size-5 -translate-y-1/2 place-items-center rounded-sm text-fg-3 hover:bg-hover hover:text-fg-1"><X className="size-3" /></button>`。
   - 行为照旧：输入后 300 毫秒没有新输入才写进仓库；回车立即写；清空按钮立即写空串；仓库被外部重置时同步输入框并取消没提交的定时器；卸载时清定时器。

**数据**：`taskFilterStore`、`useProjects()`、快照的 `pools`、`roles`、`projects`。

**交互**：任何条件变化 → 看板立刻重新筛（纯前端）；列表的查询键变化 → 从第一页重新加载（TanStack Query 自动完成）。

**状态**：没有已选条件时中间区域是空的（保持 `flex-1` 占位，把时间和搜索推到右边）。

**响应式**：≥ 800 一行放下；< 800 整条横向滚动（`FilterBar` 自带），搜索框缩到 140px。

**文案**：筛选、状态、项目、池、角色、全部项目、全部池、全部角色、以及 `TASK_STATUS_OPTIONS` 的八个词、去掉 {label}、清除筛选、搜索标题、清空搜索。

**签名**：`export function DisplayMenu({ view }: { view: TaskView })`。

**触发**：shadcn `Popover`；`<PopoverTrigger asChild><Button variant="ghost" data-display-trigger aria-label="显示"><SlidersHorizontal aria-hidden="true" /><span className="max-md:sr-only">显示</span></Button></PopoverTrigger>`。

  - 小标题 `<div className="text-12 text-fg-3">排序</div>`

  - 改排序只换排序，不动其他条件。

**文案**：显示、卡片显示、编号、池、项目、角色、进度、排序、排序方式、开始时间、用量、耗时、降序、升序。

## T5 列表 `features/tasks/TaskList.tsx`（最重要的区块之一）

可以拆：`TaskListRow.tsx`（一行）、`TaskListSkeleton.tsx`（骨架行）。

**签名**：`export function TaskList()`，无参数。

**外层**：`<div data-task-list ref={scrollRef} className="h-full overflow-auto">`（本页的滚动容器，滚动加载的观察器以它为 `root`）。里面一个**原生** `<table className="w-full table-fixed border-collapse text-13">`（不用 shadcn 的 `Table`，它外面包的横向滚动层会让表头吸顶失效）。

**表头**：`<thead className="sticky top-0 z-[var(--z-sticky)] bg-panel">` 一行 `h-8`，每格 `border-b border-line px-2 text-left text-12 font-medium text-fg-3`，数字列 `text-right`。列宽写在 `th` 上（`table-fixed` 按表头宽度排）：

| # | 表头 | `th` 宽和显示 | 单元格 |
|---|---|---|---|
| 1 | （空，内含 `<span className="sr-only">状态</span>`） | `w-10 pl-4` 总是 | `StatusIcon`（14px，`retrying={retry !== null}`，`label` 同看板卡片） |
| 2 | 编号 | `hidden w-[76px] md:table-cell` | `font-mono text-12 text-fg-3` |
| 3 | 标题 | 自适应（不写宽） | `<div className="flex min-w-0 items-center gap-2">`：标题 `<span className="min-w-0 truncate text-13 text-fg-1" title={title}>`，后面跟标记（`shrink-0`，按下表） |
| 4 | 项目 | `hidden w-[160px] md:table-cell` | `<ProjectLabel projectKey={projectKey} />` |
| 5 | 角色 | `hidden w-20 xl:table-cell` | `<Label data-label="role">{roleLabel}</Label>` |
| 6 | 池 | `hidden w-20 lg:table-cell` | `poolId` 有值 `font-mono text-12 text-fg-2`；为 null `text-12 text-fg-3`「公共排队」 |
| 7 | 用量 | `hidden w-20 text-right lg:table-cell` | `font-mono tabular-nums text-12 text-fg-2`：`formatTokens(usage.totalTokens)`，为 0 时「—」；非 0 时是一个按钮，悬停（shadcn `Tooltip`）显示 `<UsageBreakdown usage={usage} />`，点它不打开行（`stopPropagation`） |
| 8 | 耗时 | `hidden w-20 text-right md:table-cell` | `font-mono tabular-nums text-12 text-fg-2`：工作中 `<Duration from={startedAt} />`；否则 `runMs > 0 ? <Duration ms={runMs} /> : "—"` |
| 9 | 开始时间 | `w-[104px] pr-4 text-right` 总是 | `font-mono tabular-nums text-12 text-fg-3`：`formatClock(createdAt, now)` |

标题后面的标记（用 `cardMeta(worker)`，只画其中三种；另加不通过）：

| 条件 | 标记 |
|---|---|
| `kind === "queue"` | `<span data-row-flag="queue" className="shrink-0 text-12 text-fg-3">{text}</span>` |
| `kind === "retry"` | `<span data-row-flag="retry" className="inline-flex shrink-0 items-center gap-1 text-12 text-status-warning"><RotateCw className="size-3" aria-hidden="true" />{text}</span>` |
| `kind === "failure"` | `<span data-row-flag="failure" className="shrink-0 text-12 text-status-failed">{text}</span>` |
| `verdict === "fail"` | `<VerdictTag verdict="fail" />` |

**行**：`<tr data-task-row={id} tabIndex={0} className="group h-10 cursor-pointer transition-colors duration-[var(--dur-fast)] ease-[var(--ease)] hover:bg-hover focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-brand">`，每格 `border-b border-line px-2 align-middle`（第 1 格 `pl-4`、最后一格 `pr-4`）。点击或回车 → `navigate("/tasks/" + id)`；↑ / ↓ 在行之间移动焦点。

**数据**（行为照旧，照搬现在 `TaskTable.tsx` 的做法）：
- `useTasks(toTasksQuery(filters))` 的全部已加载页拼起来；快照里同编号的摘要更新鲜，投影回接口顺序（不扩大筛选结果、不改分页顺序）。
- `total` 取第一页的 `total`。

**滚动加载**（照旧）：表格后面放 `<div ref={loadMoreRef} data-load-more className="h-px" />`，`IntersectionObserver`（`root` = `data-task-list`，`rootMargin: "200px"`），进入视野且 `hasNextPage && !isFetchingNextPage` 时 `fetchNextPage()`；换查询时释放旧观察器。

**尾部**：没有下一页且有数据时，`tbody` 最后一行 `<tr><td colSpan={9} data-task-total className="h-10 text-center text-12 text-fg-3">共 {total} 个</td></tr>`。

**状态**：
- 第一页加载中：10 行骨架（`TaskListSkeleton`，每格一个 `Skeleton h-3.5`，宽度：状态 `w-3.5`、编号 `w-12`、标题 `w-3/4`、项目 `w-24`、角色 `w-10`、池 `w-10`、用量 `w-12 ml-auto`、耗时 `w-12 ml-auto`、开始时间 `w-16 ml-auto`；隐藏规则和表头一致）。
- 加载下一页：末尾 3 行同样的骨架。
- 出错（第一页）：表格换成 `<div className="flex h-full items-center justify-center"><ErrorState message={…} onRetry={() => void refetch()} /></div>`。
- 空：
  - `hasActiveFilters(filters, "list")` 为 false：`<EmptyState icon={Inbox} message="还没有任务" command={'fleet run "任务"'} />`；
  - 否则：`<EmptyState message="没有符合条件的任务" action={{ label: "清除筛选", onClick: reset }} />`。
  两种都放在 `flex h-full items-center justify-center` 的容器里，外层仍是 `data-task-list`。
- 长标题：单行省略，`title` 放全文；标记不换行，挤不下时标题先被截。

**响应式**：列按表头那一栏的规则逐档隐藏：< 800 只剩状态、标题、开始时间；800–1023 加编号、项目、耗时；1024–1279 再加池、用量；≥ 1280 全部九列。任何宽度都不横向滚动。

**文案**：编号、标题、项目、角色、池、用量、耗时、开始时间、状态、公共排队、还没有任务、没有符合条件的任务、清除筛选、共 {n} 个。
