# 总览 `#/overview` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 这是**改版**：数据和交互照旧（`overviewStore` 的时间范围和维度、`useStats` 同一个查询、点击跳转带筛选、图例开关、「其他」不可点），外观按设计提炼改：**不放大数字统计卡**，大数字卡片改成一条紧凑的「指标条」（一个白色细边框条，四格之间 1px 细线，数字 16px 中等字重）；图表放进细边框面板。

本页节奏：工作区 `bg-panel` 上：40px 视图栏（右边时间范围）→ 内容区（纵向滚动，四周 16px）：实时指标条（白）→ 统计指标条（白）→ 两张图表面板并排（≥ 1280）→ 一张通栏图表面板。块与块之间 16px。
本页核心动作：看忙不忙（实时指标条）、切时间范围、看 token 花在哪。
本页最重要的区块：O1 实时指标条和 O4 token 分布。

可以改的文件：`features/overview/**`、`pages/OverviewPage.tsx`。不再用 `StatCard`、`SectionCard`（换成 `MetricStrip` / `Metric`、`Panel`）。

## O1 实时指标条 `features/overview/LiveCards.tsx`（最重要的区块之一）

**外层**：`<div data-live-cards><MetricStrip aria-label="实时">…四个 Metric…</MetricStrip></div>`。

**四格**（数据全部来自快照，不受时间范围影响；快照没到时四格都 `loading`）：

| # | `data-stat` | label | value | extra / sub | 点击 |
|---|---|---|---|---|---|
| 1 | `slots` | 槽位占用 | `${slotsUsed} / ${slotsTotal}` | extra：占用条 `<div data-slots-bar role="img" aria-label={`已用 ${used}，容量 ${total}`} className="mt-1 h-1 w-full overflow-hidden rounded-full bg-meter-track"><div className="h-full rounded-full bg-brand" style={{ width: `${pct}%` }} /></div>`（`pct` = 已用 ÷ 容量，封顶 100，容量 0 时 0）；sub：有停用的池时「停用 {n} 个池」 | `navigate("/slots")`，`ariaLabel`「槽位占用 {used} / {total}，打开槽位页」 |
| 2 | `running` | 工作中 | `${running}` | sub：在跑的项目数 > 0 时「{n} 个项目」 | `applyFromOverview({ status: "running" })` 后 `navigate("/tasks/list")`；`ariaLabel`「工作中 {n} 个，查看任务」 |
| 3 | `queued` | 排队中 | `${queued}` | sub：公共排队 > 0 时「公共排队 {n}」 | 同上，`status: "queued"`；「排队中 {n} 个，查看任务」 |
| 4 | `retrying` | 重试中 | `${retrying}` | — | 同上，`status: "retrying"`；「重试中 {n} 个，查看任务」。`retrying > 0` 时 `valueClassName="text-status-warning"`（完整类名映射） |

**响应式**：≥ 1024 一行四格；< 1024 两行两格（`MetricStrip` 自带）。

**文案**：实时、槽位占用、工作中、排队中、重试中、停用 {n} 个池、{n} 个项目、公共排队 {n}。

## O3 统计指标条 `features/overview/StatCards.tsx`

**外层**：`<div data-stat-cards><MetricStrip aria-label="统计">…</MetricStrip></div>`。数据 `useStats(overviewStatsQuery(state))`（和 `StatsBody` 同一个查询）；加载中且没有旧数据时四格 `loading`；出错时四格值都是「—」、没有 sub。`showToday` = 时间范围不是「今日」。

| # | `data-stat` | label | value | extra | sub |
|---|---|---|---|---|---|
| 1 | `tokens` | token 用量 | `formatTokens(total.usage.totalTokens)` | `<span className="block truncate text-12 text-fg-2" title={拆分全文}><UsageBreakdown usage={total.usage} /></span>` | `showToday` 时「今日 {formatTokens(today.usage.totalTokens)}」 |
| 2 | `tasks` | 任务次数 | `formatCompact(total.tasks)` | — | `showToday` 时「今日 {formatCompact(today.tasks)}」 |
| 3 | `run-time` | 总耗时 | `formatDuration(total.runMs)` | — | `showToday` 时「今日 {formatDuration(today.runMs)}」 |
| 4 | `avg-time` | 平均耗时 | `avgRunMs === null ? "—" : formatDuration(avgRunMs)` | — | `showToday` 时「今日 {同样规则}」 |

这四格不可点。

**文案**：统计、token 用量、任务次数、总耗时、平均耗时、今日。

## O4 token 分布 `features/overview/TokenShareCard.tsx`（最重要的区块之一）

**外层**：`<div data-token-share className="h-full min-w-0"><Panel data-section="token-share" title="token 分布" right={<DimensionTabs value={dimension} onChange={setDimension} />} className="h-full">…</Panel></div>`。

**主体**（逻辑照旧）：`<div className="grid min-w-0 grid-cols-1 items-center gap-6 md:grid-cols-[160px_minmax(0,1fr)]">`：

1. 环形图：`<div role="img" aria-label={`token 分布，按${维度}，共 ${n} 项`} className="relative size-40 shrink-0 justify-self-center">`，Recharts `PieChart`：`innerRadius={52}`、`outerRadius={80}`、`stroke="var(--bg-card)"`（扇区缝的颜色 = 面板底色）、`strokeWidth={2}`、`isAnimationActive={false}`；扇区颜色 `seriesColorVar(colorIndex)`。中心：`<span className="font-mono text-16 font-medium text-fg-1">{formatTokens(合计)}</span>` + `<span className="text-12 text-fg-3">tokens</span>`（纵向居中，`pointer-events-none`）。悬停提示照旧（名字、token、占比）。
2. 明细表：shadcn `Table`（`table-fixed w-full`，`data-share-table`）。表头 `h-8`：维度名（模型 / 渠道 / 项目 / 角色）、任务数（`w-16` 右对齐）、token（`w-20` 右对齐）、占比（`w-14` 右对齐，`hidden 2xl:table-cell`——并排时太挤，只在很宽时显示）。表头文字 `text-12 font-medium text-fg-3`（颜色写在里层 `span`，避免和字号被 twMerge 合并）。每行 `h-8`、`text-13`：`ColorDot` + 名字（单行省略，「其他」用 `text-fg-2`）；数字列 `font-mono tabular-nums text-12`。
   - 行标记 `data-share-row={isOther ? "__other" : key}`；非「其他」行可点（`role="button"`、`tabIndex={0}`、`aria-label`「查看 {名字} 的任务」、`cursor-pointer hover:bg-hover`、回车同点击）：`applyFromOverview({ status: "all", range, ...按维度的那一项 })` 后 `navigate("/tasks/list")`。

**状态**：加载中且没有旧数据：左边 `Skeleton size-40 rounded-full`，右边 5 条 `Skeleton h-5 w-full`；没有数据：`<EmptyState message="这段时间还没有开跑的任务" />`。

**文案**：token 分布、模型、渠道、项目、角色、任务数、token、占比、tokens、其他、查看 {名字} 的任务。

## O5 任务次数分布 `features/overview/TasksByProjectCard.tsx`

和 O4 同一个样子，照旧的差别：标题「任务次数分布」；没有维度切换（只按项目）；环形图按 `tasks`；中心 `formatCompact(合计)` + 「任务」；明细表列：项目、任务数（`w-16`）、总耗时（`w-[88px]`）、token（`w-20`，`hidden 2xl:table-cell`）；行标记 `data-project-row`；点击 `applyFromOverview({ status: "all", range, project: key })` 后 `navigate("/tasks/list")`；外层 `data-tasks-by-project`、`data-section="tasks-by-project"`。

**文案**：任务次数分布、项目、任务数、总耗时、token、任务、这段时间没有任务。

## O6 token 趋势 `features/overview/TokenTrendCard.tsx`

**外层**：`<div data-token-trend className="min-w-0"><Panel data-section="token-trend" title="token 趋势" titleExtra={粒度} right={<DimensionTabs … />}>…</Panel></div>`。

- 粒度：`<span data-granularity={granularity} className="text-12 text-fg-3">{按小时 | 按天 | 按周}</span>`（数据到了才有）。
- 主体（逻辑照旧）：上面 `SeriesLegend`（可点开关，最后一条不能关；换维度或时间范围后隐藏状态清空），`mb-3`；下面折线图 `h-[260px] w-full max-md:h-[200px]`：网格线 `var(--chart-grid)`、只画横线；坐标轴文字 `fill: var(--text-3)`、`fontSize: 12`；线宽 2；点半径 3（描边 `var(--bg-card)` 1px），悬停点半径 5（描边 2px）；`isAnimationActive={false}`；悬停提示标题用 `formatBucketTitle`、数值 `formatTokens`。
- 视觉隐藏的数据表（`sr-only`，照旧）。

**状态**：加载中且没有旧数据：`Skeleton h-[260px] w-full max-md:h-[200px]`。

**文案**：token 趋势、按小时、按天、按周、token 趋势明细、时间段。
