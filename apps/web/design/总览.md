# 总览 `#/overview` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。

本页节奏：`bg-page` 上一列白卡片（`bg-panel`）：实时卡片行 → 细长的时间筛选条 → 统计卡片行 → 两张并排的分布卡 → 一张通栏的趋势卡。
本页核心动作：看现在忙不忙（实时卡片可点），切时间范围看用量。
本页最重要的区块：O1 实时卡片、O4 token 分布，允许写得最长。

## 页面组件 `pages/OverviewPage.tsx`

```tsx
<>
  <PageHeader title="总览" />
  <main className="min-h-0 flex-1 overflow-y-auto">
    <div data-page="overview" className="flex min-w-0 flex-col gap-4 p-6">
      <LiveCards />          {/* O1 */}
      <RangeBar />           {/* O2 */}
      <StatCards />          {/* O3 */}
      <StatsBody />          {/* O4～O6，或没数据时的合并空态 */}
    </div>
  </main>
</>
```

`StatsBody`（写在 `features/overview/StatsBody.tsx`）：读 `useStats(query)`（`query` 由 `overviewStore` 的 `range` 和 `dimension` 组成：`{ range: range.kind, from: range.from, to: range.to, dimension }`）。

- 加载中且没有旧数据：O4、O5、O6 各自画自己的加载态（见各区块）。
- 出错：一张 `SectionCard`，里面 `ErrorState message={error.message} onRetry={refetch}`，替换 O4～O6。标记 `data-stats-error`。
- 加载完且 `total.tasks === 0` 且 `total.usage.totalTokens === 0`：一张 `SectionCard`，里面 `EmptyState icon={Inbox} message="这段时间没有任务"`，替换 O4～O6。标记 `data-stats-empty`。
- 其余：

```tsx
<div className="grid min-w-0 grid-cols-1 gap-4 lg:grid-cols-2">
  <TokenShareCard />       {/* O4 */}
  <TasksByProjectCard />   {/* O5 */}
</div>
<TokenTrendCard />         {/* O6 */}
```

O3 和 `StatsBody` 共用同一个 `useStats` 查询（同一个键，TanStack Query 只发一次请求）。

## O1 实时卡片行 `features/overview/LiveCards.tsx`

**外层**：`<section data-live-cards aria-label="实时" className="grid grid-cols-2 gap-4 lg:grid-cols-4">`。

**元素**：四张 `StatCard`（DESIGN.md 4.3），从左到右：

| # | `data-stat` | label | value | lines | 点击 |
|---|---|---|---|---|---|
| 1 | `slots` | 槽位占用 | `{live.slotsUsed} / {live.slotsTotal}` | 第 1 行：占用条（见下）；第 2 行：`停用 {n} 个池`（n = `pools` 里 `enabled` 为 false 的个数，为 0 时这一行不出现） | 去 `#/slots` |
| 2 | `running` | 工作中 | `{live.running}` | `{m} 个项目`（m = `snapshot.workers` 里状态为工作中的不同 `projectKey` 数；为 0 时这一行不出现） | 任务页，状态「工作中」 |
| 3 | `queued` | 排队中 | `{live.queued}` | `公共排队 {sharedQueued}`（为 0 时不出现） | 任务页，状态「排队中」 |
| 4 | `retrying` | 重试中 | `{live.retrying}` | 无 | 任务页，状态「重试中」 |

占用条：`<div data-slots-bar className="mt-2 h-1.5 w-full overflow-hidden rounded-full bg-meter-track">`，里面一根 `h-full rounded-full bg-st-running`，宽度 `min(100, slotsUsed / slotsTotal × 100)%`；`slotsTotal` 为 0 时宽度 0。`role="img"`，`aria-label="已用 {slotsUsed}，容量 {slotsTotal}"`。

第 4 张卡的大数字在 `retrying > 0` 时传 `valueClassName="text-st-warning"`（其余三张不传，默认 `text-fg-1`）。

**数据**：`useSnapshotStore` 的 `snapshot.live`、`snapshot.sharedQueued`、`snapshot.pools`、`snapshot.workers`。

**交互**：点卡片跳转。「任务页，状态 X」= `taskFilterStore.applyFromOverview({ status: X })` 然后 `navigate("/tasks")`，X 分别是 `running`、`queued`、`retrying`。每张卡的 `ariaLabel`：「槽位占用 23 / 40，打开槽位页」「工作中 23 个，查看任务」「排队中 4 个，查看任务」「重试中 1 个，查看任务」（数字随数据）。

**状态**：`snapshot` 为 null（还没收到第一份快照）：四张卡 `loading`。断线时照常显示最后一份快照的数（外层内容整体变淡由骨架负责）。

**响应式**：≥ 1024 一行四张；< 1024 两行两张。

**文案**：槽位占用、工作中、排队中、重试中、停用 {n} 个池、{m} 个项目、公共排队 {n}。

## O2 时间筛选条 `features/overview/RangeBar.tsx`

**外层**：`<section data-range-bar className="flex flex-wrap items-center gap-3 rounded-lg border border-line bg-panel px-5 py-3">`。

**元素**：
1. 标签「时间范围」：`text-12 text-fg-3`。
2. `RangePicker variant="segmented" name="overview-range"`，值和改动都走 `overviewStore.range` / `setRange`。
3. 右侧（`ml-auto`）一个小字：统计分段的粒度，`text-12 text-fg-3`，内容按 `useStats` 返回的 `granularity`：`hour` →「按小时」，`day` →「按天」，`week` →「按周」；数据还没到时不显示。标记 `data-granularity`。

**数据**：`overviewStore`；粒度来自 `useStats`（和 O3 同一个查询）。

**交互**：切档位立刻重新请求统计（TanStack Query 换键）；切换期间 O3～O6 保留旧数据（`keepPreviousData`），不闪空。

**状态**：无单独状态。

**响应式**：< 800 时分段控件换行到标签下面（`flex-wrap` 自然完成）。

**文案**：时间范围、按小时、按天、按周；档位文字由 `RangePicker` 负责。

## O3 统计卡片行 `features/overview/StatCards.tsx`

**外层**：`<section data-stat-cards aria-label="统计" className="grid grid-cols-2 gap-4 lg:grid-cols-4">`。

**元素**：四张 `StatCard`（不可点）：

| # | `data-stat` | label | value | lines |
|---|---|---|---|---|
| 1 | `tokens` | token 用量 | `formatTokens(total.usage.totalTokens)` | `<UsageBreakdown usage={total.usage} />`；`今日 {formatTokens(today.usage.totalTokens)}` |
| 2 | `tasks` | 任务次数 | `formatCompact(total.tasks)` | `今日 {formatCompact(today.tasks)}` |
| 3 | `run-time` | 总耗时 | `formatDuration(total.runMs)` | `今日 {formatDuration(today.runMs)}` |
| 4 | `avg-time` | 平均耗时 | `total.avgRunMs === null ? "—" : formatDuration(total.avgRunMs)` | `今日 {today.avgRunMs === null ? "—" : formatDuration(today.avgRunMs)}` |

所选档位是「今日」时，四张卡都**不显示**「今日 …」那一行（和大数字重复）。第 1 张的 `UsageBreakdown` 那行 `truncate`，`title` 放全文。

**数据**：`useStats`（见页面组件）。

**交互**：无。

**状态**：加载中且没有旧数据：四张 `loading`；出错：四张的 value 显示「—」、lines 为空（错误信息由 `StatsBody` 那张卡说）。

**响应式**：同 O1。

**文案**：token 用量、任务次数、总耗时、平均耗时、今日 {…}。

## O4 token 分布 `features/overview/TokenShareCard.tsx`（最重要的区块之一）

**外层**：`<SectionCard data-section="token-share" title="token 分布" right={<DimensionTabs value={dimension} onChange={setDimension} />}>`，根元素加 `data-token-share`。

**元素**：主体 `<div className="grid min-w-0 grid-cols-1 items-center gap-6 md:grid-cols-[160px_minmax(0,1fr)]">`：

1. **环形图**（左，`relative h-40 w-40 shrink-0 justify-self-center`）：shadcn `ChartContainer`（`config` 用每个 `tokenShare` 项生成：`{ [key或"other"]: { label, color: seriesColorVar(colorIndex) } }`）包 Recharts `PieChart`：`Pie data={tokenShare} dataKey="tokens" nameKey="label" innerRadius={52} outerRadius={80} paddingAngle={0} stroke="var(--bg-panel)" strokeWidth={2} isAnimationActive={false}`，每个扇区 `<Cell fill={seriesColorVar(item.colorIndex)} />`。悬停扇区出 `ChartTooltip`（`ChartTooltipContent hideLabel`），内容「{label}　{formatTokens(tokens)}　{formatPercent(tokens, 合计)}」。
   中心叠一层（`pointer-events-none absolute inset-0 flex flex-col items-center justify-center`）：合计 `formatTokens(Σ tokens)`（`font-mono text-22 font-semibold text-fg-1`），下面「tokens」（`text-11 text-fg-3`）。
   整个图 `role="img"`，`aria-label="token 分布，按{维度名}，共 {n} 项"`（维度名：模型 / 渠道 / 项目 / 角色）。
2. **明细表**（右）：shadcn `Table`，`<Table data-share-table className="text-13">`。表头（`text-12 font-medium text-fg-3`）：`{维度名}` | 任务数 | token | 占比（占比列 `hidden xl:table-cell`）。每行（`tokenShare` 的顺序，最多 9 行）：
   - 第 1 格：`flex items-center gap-2 min-w-0`：`ColorDot colorVar={seriesColorVar(item.colorIndex)}` + 名称（`truncate`，`title` 放全文；「其他」用 `text-fg-2`）。
   - 任务数：`font-mono tabular-nums text-right`，`formatCompact(item.tasks)`。
   - token：`font-mono tabular-nums text-right`，`formatTokens(item.tokens)`。
   - 占比：`font-mono tabular-nums text-right text-fg-2`，`formatPercent(item.tokens, 合计)`。
   行标记 `data-share-row={item.isOther ? "__other" : item.key}`。

**数据**：`useStats` 的 `tokenShare`；维度来自 `overviewStore.dimension`。

**交互**：
- 维度切换：`setDimension`，O4 和 O6 一起变（同一个仓库值），重新请求统计。
- 点表格一行（「其他」那行不可点，不加悬停效果）：整行 `cursor-pointer hover:bg-hover`，键盘可聚焦（`tabIndex={0}`，回车同点击）。点击 = `taskFilterStore.applyFromOverview({ status: "all", range: 当前 range, <维度对应字段>: item.key })`，然后 `navigate("/tasks")`。维度对应字段：模型 → `model`，渠道 → `channel`，项目 → `project`，角色 → `role`。行的 `aria-label`：「查看 {名称} 的任务」。
- 扇区不可点（只有悬停提示）。

**状态**：
- 加载中且没有旧数据：环形图位置画 160×160 的 `Skeleton`（圆形 `rounded-full`），表格画 5 行 `Skeleton`（高 20，间距 8）。
- `tokenShare` 为空（范围内有任务但一次都没开跑，例如全在排队）：卡片主体换成 `EmptyState message="这段时间还没有开跑的任务"`。
- 名称很长：截断 + `title`。

**响应式**：≥ 800（`md`）左图右表；< 800 图在上、表在下。1024～1279 两张分布卡并排时占比列隐藏。

**文案**：token 分布、模型 / 渠道 / 项目 / 角色、任务数、token、占比、tokens、其他、这段时间还没有开跑的任务。

## O5 任务次数分布 `features/overview/TasksByProjectCard.tsx`

**外层**：`<SectionCard data-section="tasks-by-project" title="任务次数分布">`，根元素加 `data-tasks-by-project`。没有维度切换（只按项目）。

**元素**：结构同 O4，区别：
1. 环形图 `dataKey="tasks"`；颜色 `seriesColorVar(item.colorIndex)`（服务端给的是项目色位置，和全站项目色一致）；中心合计 `formatCompact(Σ tasks)`，下面「任务」；`aria-label="任务次数分布，按项目，共 {n} 项"`；悬停提示「{项目名}　{tasks} 个　{占比}」。
2. 明细表表头：项目 | 任务数 | 总耗时 | token（`token` 列 `hidden xl:table-cell`）。每行：色点 + 项目名；`formatCompact(tasks)`；`formatDuration(runMs)`；`formatTokens(tokens)`。行标记 `data-project-row={item.isOther ? "__other" : item.key}`。

**数据**：`useStats` 的 `tasksByProject`。

**交互**：点一行（「其他」除外）= `applyFromOverview({ status: "all", range: 当前 range, project: item.key })` 后去任务页。`aria-label`：「查看 {项目名} 的任务」。

**状态**：加载同 O4；`tasksByProject` 为空：`EmptyState message="这段时间没有任务"`（正常不会出现，整页空态先拦住）。

**响应式**：同 O4。

**文案**：任务次数分布、项目、任务数、总耗时、token、任务、其他。

## O6 token 趋势 `features/overview/TokenTrendCard.tsx`

**外层**：`<SectionCard data-section="token-trend" title="token 趋势" right={<DimensionTabs value={dimension} onChange={setDimension} />}>`，根元素加 `data-token-trend`。

**元素**：
1. 图例：`SeriesLegend items={tokenTrend 每条线 → { key: isOther ? "__other" : key, label, colorVar: seriesColorVar(colorIndex), hidden }} onToggle={切换隐藏}`，放在图上方，`mb-3`。
2. 折线图：shadcn `ChartContainer className="h-[280px] w-full"` 包 Recharts `LineChart`，数据把 `buckets` 和各线 `points` 转成行：`{ bucket: iso, [线的键]: 数 }`。
   - `CartesianGrid vertical={false} stroke="var(--chart-grid)"`。
   - `XAxis dataKey="bucket" tickLine={false} axisLine={false} tickMargin={8} minTickGap={24} tickFormatter={(iso) => formatBucketLabel(iso, granularity)}`，刻度文字 `fill: var(--text-3)`、字号 11。
   - `YAxis tickLine={false} axisLine={false} width={48} tickFormatter={formatTokens}`，同样字色字号。
   - 每条线：`Line type="monotone" dataKey={键} stroke={seriesColorVar(colorIndex)} strokeWidth={2} dot={{ r: 3 }} activeDot={{ r: 5 }} isAnimationActive={false} hide={hidden}`。
   - `ChartTooltip`（`ChartTooltipContent`）：标题 `formatBucketTitle(iso, granularity)`，每行「色点 名称 数值」，数值 `formatTokens`，隐藏的线不出现。
   - 整个图外包 `role="img"`，`aria-label="token 趋势，按{维度名}，{n} 条线，{m} 个时间段"`；另附一张 `sr-only` 的表（行 = 时间段，列 = 各线）给读屏。
3. `formatBucketLabel`、`formatBucketTitle` 由地基路加在 `lib/format.ts`（主控会追加这两个函数的规格：`hour` →「14:00」/「09-25 14:00」；`day` →「09-25」/「09-25」；`week` →「09-22」/「09-22 起一周」）；本路直接 import。

**数据**：`useStats` 的 `buckets`、`granularity`、`tokenTrend`；维度同 O4。

**交互**：
- 点图例项切换该线显示；至少保留一条可见（只剩一条时再点它不响应）。维度或时间范围变化时，隐藏状态清空。
- 悬停出提示；键盘不需要逐点导航（读屏用附表）。

**状态**：加载中且没有旧数据：图区画一块 `Skeleton height={280}`；`buckets` 只有 1 个时照常画（只有点，没有线段）。

**响应式**：通栏；< 800 时图高 220px。

**文案**：token 趋势、模型 / 渠道 / 项目 / 角色、其他。

## 本页交互检查会找的东西

期望值来自演示数据单测（`api/demo/scenarios.test.ts`，主控验收时核对数字）。

| 位置 | 操作 | 断言 |
|---|---|---|
| `?demo=busy#/overview` 的 `[data-stat="slots"]` | 读文字 | 含「{busy.live.slotsUsed} / {busy.live.slotsTotal}」 |
| `[data-stat="queued"]` | 点击 | 地址变成 `#/tasks`，任务页状态筛选为「排队中」 |
| `[data-stat="retrying"]` | 点击 | 地址 `#/tasks`，状态筛选为「重试中」 |
| `[data-seg="overview-range:today"]` | 点击 | `[data-stat="tokens"]` 里不再出现「今日」 |
| `[data-seg="dimension:project"]`（O4 里那个） | 点击 | O4 表头第一格变成「项目」，O6 图例项数等于 busy 按项目的分布项数 |
| `[data-share-row]` 第一行 | 点击 | 地址 `#/tasks`，已选条件里出现对应维度的小标签 |
| `[data-share-row="__other"]` | 查（busy 各维度都不超过 8 项） | 不存在 |
| O6 的第一个 `[data-legend]` | 点击 | 它的 `aria-pressed` 变 `false` |
| `?demo=empty#/overview` | 打开 | 出现 `[data-stats-empty]`，文字「这段时间没有任务」；四张实时卡片的数都是 0 |
| `?demo=disabled#/overview` 的 `[data-stat="slots"]` | 读文字 | 含「停用 {disabled 场景停用池数} 个池」 |
