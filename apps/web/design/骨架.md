# 骨架（每页都有）—— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 地基路读 S1～S5；搜索路只读 S6。

本页节奏：整个窗口是 `bg-window` 浅灰：顶上 38px 窗口栏，左边 240px 侧栏，两者都没有边框；右下是一块 `bg-panel` 近白的工作区面板（1px `border-line`、圆角 6、`shadow-panel`），右边和下边离窗口边缘 8px，上边贴着窗口栏，左边贴着侧栏（侧栏收起时左边也留 8px）。
本页核心动作：侧栏切页、窗口栏搜任务、看一眼占用。
本页最重要的区块：S2 侧栏。

整体结构（`app/AppShell.tsx`）：

```tsx
<TooltipProvider delayDuration={300}>
  <div data-app className="flex h-svh flex-col bg-window text-fg-1">
    <WindowBar />                                            {/* S1 */}
    <div className="flex min-h-0 flex-1">
      <AppSidebar />                                         {/* S2：≥1024 常驻；<1024 只渲染抽屉 */}
      <main
        data-workspace
        data-offline={offline ? "true" : "false"}
        className={`mb-2 mr-2 flex min-w-0 flex-1 flex-col overflow-hidden rounded-lg border border-line bg-panel shadow-panel ${sidebarDocked ? "" : "ml-2"}`}
      >
        <ShellBanners />                                     {/* S4 */}
        <ConnectionGate>                                     {/* S5 */}
          <Outlet />                                         {/* 页面：ViewBar → (FilterBar) → data-page-body */}
        </ConnectionGate>
      </main>
    </div>
    <SearchDialog />                                         {/* S6，开关在 searchStore */}
  </div>
</TooltipProvider>
```

- `sidebarDocked` = 窗口 ≥ 1024 且 `sidebarStore.open` 为 true。
- 窗口宽度判断用地基路新写的 `src/hooks/useMediaQuery.ts`：`export function useMediaQuery(query: string): boolean`（`matchMedia` + `change` 事件，首帧直接读 `matchMedia(query).matches`）。桌面判断统一写 `useMediaQuery("(min-width: 1024px)")`，手机判断 `useMediaQuery("(max-width: 799px)")`。
- `AppShell` 挂载时的行为照旧：订阅数据源的快照流写进 `snapshotStore`（含重连回调）、`useLiveInvalidation()`、`initNow(dataSource)`、`initWorkerStore(dataSource)`。
- 快捷键：在 `window` 上监听 `keydown`，`(event.ctrlKey || event.metaKey) && event.key.toLowerCase() === "k"` 时 `preventDefault()` 并 `searchStore.toggle()`；卸载时移除。
- 窗口从 < 1024 变成 ≥ 1024 时 `setDrawerOpen(false)`。
- 滚动约定：`data-app`、`data-workspace` 都不滚动；每页的 `data-page-body` 或它里面的区域自己滚动。`ConnectionGate` 渲染 `children` 时不包任何额外元素，保证 `data-workspace` 的纵向弹性布局成立。

## S1 窗口栏 `app/WindowBar.tsx`

**外层**：`<header data-window-bar className="relative flex h-[var(--window-bar-h)] shrink-0 items-center gap-2 px-2">`，没有底色（透出 `bg-window`）、没有边框。

**元素**（从左到右）：

1. 侧栏开关：`<Button variant="ghost" size="icon" data-sidebar-toggle aria-label={…} onClick={…}>`，图标 `PanelLeft` 16px。
   - 窗口 ≥ 1024：点一下 `sidebarStore.toggle()`；`aria-label` 在侧栏显示时是「收起侧栏」，隐藏时是「展开侧栏」；`aria-pressed={open}`。
   - 窗口 < 1024：点一下 `setDrawerOpen(true)`；`aria-label="打开侧栏"`。
2. 搜索入口：`<button type="button" data-search-trigger aria-label="搜索任务" aria-keyshortcuts="Control+K" onClick={() => setSearchOpen(true)}>`。
   - ≥ 800：绝对定位在窗口栏正中：`absolute left-1/2 top-1/2 flex h-7 w-[320px] -translate-x-1/2 -translate-y-1/2 items-center gap-2 rounded-md border border-line bg-card px-2 text-12 text-fg-3 shadow-card transition-colors hover:border-line-strong hover:text-fg-2`；内容：`Search` 14px → 文字「搜索任务」→ 最右（`ml-auto`）一个 `<Kbd>`，文字是「Ctrl K」（`navigator.userAgent` 含 `Mac` 时写「⌘K」）。
   - < 800：不再居中，换成紧跟在侧栏开关后面的图标按钮 `<Button variant="ghost" size="icon" data-search-trigger aria-label="搜索任务">` + `Search` 16px。两种写法二选一渲染，用 `useMediaQuery("(max-width: 799px)")` 判断。
3. 占用数：快照到了才渲染。React Router `<Link to="/slots" data-occupancy aria-label={…} className="ml-auto inline-flex h-7 items-center gap-1 rounded-md px-2 text-12 text-fg-2 transition-colors hover:bg-hover hover:text-fg-1">`：
   - 「槽位」+ `<span className="font-mono text-fg-1">{slotsUsed}/{slotsTotal}</span>`；
   - `live.queued > 0` 时再跟 `<span aria-hidden="true">·</span>` +「排队」+ `<span className="font-mono text-fg-1">{queued}</span>`；
   - < 800：「槽位」「排队」两个词和排队那一段都隐藏（`max-md:hidden`），只剩 `23/40`。
   - `aria-label`：「槽位 {used}/{total}，排队 {queued}，打开槽位页」（排队为 0 时去掉「，排队 {queued}」）。

**数据**：`snapshotStore.snapshot.live`（`slotsUsed`、`slotsTotal`、`queued`）；`sidebarStore`；`searchStore`。

**状态**：快照还没到时占用数不渲染，其余照常。断线时不在这里提示（S4 负责）。

**文案**：收起侧栏、展开侧栏、打开侧栏、搜索任务、Ctrl K、⌘K、槽位、排队。

## S2 侧栏 `app/AppSidebar.tsx`

**结构**：同一份侧栏内容 `SidebarBody`（本文件内部组件，参数 `{ onNavigate?: () => void }`）在两个地方用：

- **桌面（≥ 1024）**：`<aside data-nav data-state={open ? "open" : "closed"} className={open ? "flex w-[var(--sidebar-w)] shrink-0 flex-col overflow-hidden pb-2" : "hidden"}>`，里面放 `<SidebarBody />`。没有背景（透出 `bg-window`）、没有边框。
- **窄屏（< 1024）**：桌面那个 `aside` 不渲染；改用 `<Sheet open={drawerOpen} onOpenChange={setDrawerOpen}>` + `<SheetContent side="left" data-nav-drawer aria-describedby={undefined} className="flex flex-col pb-2">`，里面先放 `<SheetTitle className="sr-only">菜单</SheetTitle>`，再放 `<SidebarBody onNavigate={() => setDrawerOpen(false)} />`。

**`SidebarBody` 的元素**（从上到下）：

1. 产品行：`<div className="flex h-10 shrink-0 items-center gap-2 px-3">`
   - 产品标记：`<span aria-hidden="true" className="grid size-5 shrink-0 place-items-center rounded-md bg-team text-12 font-medium text-on-brand">F</span>`
   - 产品名：`<span className="truncate text-13 font-medium text-fg-1">fleet studio</span>`
   - 版本号：`<span className="shrink-0 font-mono text-12 text-fg-3">v0.3</span>`
2. 主菜单：`<nav aria-label="主菜单" className="flex flex-col gap-px px-2">`，三项，按这个顺序：

| 文字 | 图标 | 去向 | 标记 |
|---|---|---|---|
| 任务 | `ListChecks` | `tasksPath(lastTasksView)` | `data-nav-item="tasks"` |
| 槽位 | `Layers` | `/slots` | `data-nav-item="slots"` |
| 总览 | `LayoutDashboard` | `/overview` | `data-nav-item="overview"` |

   每项是 React Router `<Link>`（当前项自己判断，不用 `NavLink` 的 active）：
   - 类名：`group flex h-7 items-center gap-2 rounded-md px-2 text-13 font-medium text-fg-2 transition-colors duration-[var(--dur-fast)] ease-[var(--ease)] hover:bg-hover hover:text-fg-1 aria-[current=page]:bg-selected aria-[current=page]:text-fg-1`
   - 图标 16px：`size-4 shrink-0 text-fg-3 group-aria-[current=page]:text-fg-1`
   - 文字：`<span className="truncate">`
   - 当前项加 `aria-current="page"`。判断：「槽位」= 路径以 `/slots` 开头；「总览」= 路径以 `/overview` 开头；「任务」= 路径以 `/tasks` 开头，并且（是详情页，即路径不是 `/tasks` 也不是 `/tasks/list`，或者 `taskFilterStore.project` 为空）。
   - 「任务」那一项点击时先 `taskFilterStore.set({ project: undefined })` 再跳转（清掉侧栏项目的筛选）。
   - 「任务」右侧的进行中数：`<span data-nav-count className="ml-auto font-mono text-12 text-fg-3 group-aria-[current=page]:text-fg-2">{live.running + live.queued}</span>`，为 0 或快照没到时不渲染。
   - 每项点击后调用 `onNavigate?.()`（窄屏关抽屉）。
3. 项目分组：快照到了且 `snapshot.projects` 不为空时才渲染。`<div className="mt-4 flex min-h-0 flex-1 flex-col">`：
   - 分组标题：`<div className="flex h-7 shrink-0 items-center px-4 text-12 font-medium text-fg-3">项目</div>`
   - 列表：`<nav aria-label="项目" className="flex min-h-0 flex-col gap-px overflow-y-auto px-2">`，按 `snapshot.projects` 的原顺序（有在跑的在前），每个项目一项 `<Link data-nav-project={project.key} to={tasksPath(lastTasksView)} title={project.name}>`，类名和主菜单项完全一样（同一个类名常量）：
     - 左边 `<span aria-hidden="true" className="grid size-4 shrink-0 place-items-center"><ColorDot colorVar={projectColorVar(project.colorIndex)} size={8} /></span>`
     - 名字 `<span className="truncate">{project.name}</span>`
     - 右边进行中数 `project.counts.running + project.counts.queued`，样式同 `data-nav-count`（标记换成 `data-nav-project-count`），为 0 不渲染。
     - 点击：`taskFilterStore.reset()`，再 `taskFilterStore.set({ project: project.key })`，然后跳转、`onNavigate?.()`。
     - 当前项：路径是 `/tasks` 或 `/tasks/list`，且 `taskFilterStore.project === project.key`，加 `aria-current="page"`。

**数据**：`snapshotStore`（`live`、`projects`）、`taskFilterStore`（`project`、`set`、`reset`）、`viewStore`（`lastTasksView`）、`sidebarStore`、路由的 `useLocation().pathname`。

**交互**：Tab 依次经过主菜单三项和项目各项，回车跳转。侧栏没有自己的滚动条，只有项目列表在项目多时自己纵向滚动。

**状态**：快照没到：进行中数和项目分组都不渲染。没有项目：项目分组不渲染。

**响应式**：≥ 1024 常驻，可由 S1 的开关隐藏（隐藏时工作区左边留 8px）；< 1024 只有抽屉，点菜单项、点遮罩、按 Esc 都关抽屉。

**文案**：fleet studio、v0.3、主菜单、任务、槽位、总览、项目、菜单。

## S3 工作区 `app/AppShell.tsx`

见本文件开头的整体结构。补充：

- 断线时（`connection === "lost"` 且 `everOpened`）`data-workspace` 上 `data-offline="true"`，全局样式让里面的 `[data-page-body]` 变成 60% 不透明；视图栏、筛选栏、提示条不变淡。
- 工作区里第一层依次是：提示条（S4，有才渲染）→ 页面（`ViewBar` → `FilterBar`（只有任务页）→ `data-page-body`）。
- 工作区宽度 < 800 时圆角和边框照旧，外边距从 8px 改成 4px（`max-md:mb-1 max-md:mr-1`，侧栏不在时 `max-md:ml-1`）。

## S6 搜索弹窗 `app/search/SearchDialog.tsx`（搜索路）

地基路只建占位：`export function SearchDialog() { return null; }`。搜索路覆盖成下面的样子；要拆子组件只能放在 `app/search/`、以 `SearchDialog` 开头（如 `SearchDialogResult.tsx`）。

**外层**：shadcn `Dialog`（`open={searchStore.open}`、`onOpenChange={searchStore.setOpen}`）→ `DialogContent` 加 `data-search-dialog`，类名在默认值上覆盖成 `top-[12vh] w-[min(560px,calc(100vw-24px))] translate-y-0 overflow-hidden p-0`（贴近顶部，水平居中）。里面先放 `<DialogTitle className="sr-only">搜索任务</DialogTitle>`。

**元素**：

1. 输入行：`<div className="flex h-11 items-center gap-2 border-b border-line px-3">`
   - `Search` 16px `text-fg-3`
   - 输入框：`<input data-search-input role="combobox" aria-expanded="true" aria-controls="search-results" aria-activedescendant={当前项的 id} aria-autocomplete="list" autoFocus placeholder="按标题或编号搜索" value={query} onChange={…} className="h-full min-w-0 flex-1 bg-transparent text-13 text-fg-1 outline-none placeholder:text-fg-3">`（受控）
   - 右边 `<Kbd>Esc</Kbd>`，< 800 隐藏（`max-md:hidden`）。
2. 结果区：`<div className="max-h-[min(360px,60vh)] overflow-y-auto p-1">`
   - 关键词为空时，列表上方一行小标题 `<div className="px-2 pb-1 pt-1.5 text-12 text-fg-3">最近</div>`；有关键词时不显示。
   - 列表 `<ul id="search-results" role="listbox" aria-label="搜索结果">`，每条：
     `<li id={"search-option-" + id} role="option" aria-selected={active} data-search-result={id} data-active={active ? "true" : "false"} className="flex h-9 cursor-pointer items-center gap-2 rounded-md px-2 data-[active=true]:bg-hover">`
     - `StatusIcon`（14px；`status` 用任务状态，`retrying` = `retry !== null`；`label` = `STATUS_META[status].label`）
     - 编号 `<span className="w-14 shrink-0 font-mono text-12 text-fg-3">{id}</span>`
     - 标题 `<span className="min-w-0 flex-1 truncate text-13 text-fg-1" title={title}>{title}</span>`
     - `<ProjectLabel projectKey={projectKey} />`，外面包一层 `max-md:hidden shrink-0 max-w-[160px]`
     - 当前项最右边 `CornerDownLeft` 14px `text-fg-3`（`aria-hidden`），非当前项不渲染。

**数据**：
- 关键词 `query` 存在组件自己的状态里；每次弹窗打开时清空 `query`、当前项回到第 0 条。
- 快照结果：`matchLiveTasks(snapshot?.workers ?? [], query)`（`lib/search.ts`），随输入立刻变。
- 接口结果：`useTaskSearch(debouncedQuery)`（`api/queries.ts`），`debouncedQuery` 是 `query` 停止输入 200 毫秒后的值（本地定时器，卸载时清掉）。
- 显示的列表 = `mergeSearchResults(快照结果, 接口结果?.items ?? [])`，最多 8 条。

**交互**：
- ↓ / ↑：当前项下移 / 上移，到头绕回；鼠标移到哪条哪条就是当前项。
- 回车或点击一条：`navigate("/tasks/" + id)`，然后关弹窗。
- Esc、点遮罩：关弹窗（Radix 自带）。
- 当前项变化时让它滚进可视区（`scrollIntoView({ block: "nearest" })`）。

**状态**：
- 有关键词、合并后为空、接口还在请求：3 条骨架行（`Skeleton` `h-9 w-full`，间距 `gap-1`）。
- 有关键词、合并后为空、接口已返回：`<p className="px-2 py-8 text-center text-13 text-fg-2">没有找到任务</p>`。
- 接口出错且合并后为空：同样位置写「搜索失败：{错误信息}」。
- 快照没到：只用接口结果；关键词为空时列表为空，这时显示「没有找到任务」。

**响应式**：宽度随窗口缩到 `100vw - 24px`；< 800 隐藏 `Esc` 提示和项目标签。

**文案**：搜索任务、按标题或编号搜索、Esc、最近、搜索结果、没有找到任务、搜索失败：。
