# 骨架（每页都有）—— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。

本页节奏：左侧 `bg-panel` 侧栏（右边一条 `border-line`）→ 右侧 `bg-page` 内容区；内容区顶上 `bg-panel` 顶栏（底边一条 `border-line`）。
本页核心动作：左侧菜单切换三页。
本页最重要的区块：S1 左侧菜单。

整体结构（`AppShell.tsx`）：

```tsx
<SidebarProvider open={!collapsed} onOpenChange={...} style={{ "--sidebar-width": "var(--sidebar-w)", "--sidebar-width-icon": "var(--sidebar-w-collapsed)" }}>
  <AppSidebar />                         {/* S1 */}
  <SidebarInset className="flex h-svh min-w-0 flex-col overflow-hidden bg-page">  {/* 右侧：高度锁在视口，滚动交给各页 */}
    <ShellBanners />                     {/* S3，在页面自己渲染的顶栏之上 */}
    <ConnectionGate>                     {/* S4：连不上服务时替换整个内容区 */}
      <Outlet />                         {/* 页面：先渲染 PageHeader（S2），再渲染页面内容 */}
    </ConnectionGate>
  </SidebarInset>
</SidebarProvider>
```

滚动约定：`SidebarInset` 本身不滚动。每个页面组件渲染的最外层是 `<>` 片段：先 `PageHeader`（固定在上），再一个 `<main className="min-h-0 flex-1 overflow-y-auto">` 作为这一页的滚动容器（总览、槽位这样用）；任务页例外，它的主区域不整体滚动，表格卡片和详情卡片各自滚动（见 `design/任务.md`）。`ConnectionGate` 渲染 `children` 时不包任何额外的元素，保证上面的弹性布局成立。

`AppShell` 挂载时：订阅数据源的快照流写进 `snapshotStore`；调用 `useLiveInvalidation()`；渲染 `<Toaster position="bottom-right" />`（sonner，也可以放在 `main.tsx`）。

## S1 左侧菜单 `app/AppSidebar.tsx`

**外层**：shadcn `Sidebar collapsible="icon"`，根元素加 `data-nav` 和 `data-collapsed={collapsed ? "true" : "false"}`。展开宽 `--sidebar-w`（220px），收起宽 `--sidebar-w-collapsed`（64px）。背景 `bg-panel`，右边框 `border-line`。高度占满视口，不随内容区滚动。

**元素**（从上到下）：

1. `SidebarHeader`：高 56px（与顶栏等高），`flex items-center gap-2 px-4`；左边 24×24 的产品标记（`rounded-md bg-brand text-on-brand`，里面一个 `text-12 font-semibold` 的「F」）；右边产品名「fleet studio」（`text-14 font-semibold text-fg-1`）后跟版本号「v0.2」（`font-mono text-11 text-fg-3`）。收起时只剩产品标记，居中。底边 `border-b border-line`。
2. `SidebarContent` → 一个 `SidebarMenu`，`px-3 py-3 gap-1`，三项（按这个顺序）：

| 文字 | 图标 | 去向 | 标记 |
|---|---|---|---|
| 总览 | `LayoutDashboard` | `#/overview` | `data-nav-item="overview"` |
| 槽位 | `Layers` | `#/slots` | `data-nav-item="slots"` |
| 任务 | `ListChecks` | `#/tasks` | `data-nav-item="tasks"` |

   每项用 `SidebarMenuButton asChild` 包 React Router 的 `NavLink`：高 40px（`h-10`）、`rounded-md px-3 gap-3`、图标 18px；默认 `text-fg-2`、图标 `text-fg-3`；悬停 `bg-hover`；当前页（`NavLink` 的 active，`/tasks/:id` 也算任务）`bg-selected text-brand`、图标 `text-brand`，并加 `aria-current="page"`。收起时只显示图标，文字进 shadcn 的提示卡（`tooltip={文字}`，右侧弹出）。
   任务那一项右侧（展开时）显示进行中的任务数小徽标：`ml-auto rounded-sm bg-hover px-1.5 font-mono text-11 text-fg-2`，数字 = `snapshot.live.running + snapshot.live.queued`，为 0 时不显示；收起时不显示。标记 `data-nav-count`。
3. `SidebarFooter`：`px-3 pb-3`，一个 32×32 的幽灵图标按钮（shadcn `Button variant="ghost" size="icon"`），展开时图标 `PanelLeftClose`、收起时 `PanelLeftOpen`，`aria-label` 分别是「收起菜单」「展开菜单」，标记 `data-nav-toggle`。点击切换 `sidebarStore.collapsed` 并写进本地存储。

**数据**：进行中任务数来自 `snapshotStore`；当前页来自路由。

**交互**：
- 点菜单项切页；键盘 Tab 能依次聚焦三项和收起按钮，回车打开。
- 快捷键：不做（shadcn Sidebar 自带的 Ctrl+B 快捷键要去掉）。
- 窗口宽度 < 1024px：强制收起，收起按钮隐藏（`hidden lg:inline-flex`）。窗口变回 ≥ 1024 时恢复成存储里的状态。
- shadcn Sidebar 在手机宽度会变成抽屉（Sheet）；本项目最小验收宽度 800px，**不用抽屉模式**：把判断手机的断点设成 0（或直接不渲染抽屉分支），800px 时仍是 64px 的图标栏。

**状态**：快照还没到时徽标不显示；其余没有数据依赖。

**响应式**：见交互。

**文案**：总览、槽位、任务、fleet studio、v0.2、收起菜单、展开菜单。

## S2 顶栏 `app/PageHeader.tsx`

**签名**：`{ title: string; right?: ReactNode }`（全站唯一接收参数的骨架区块）。

**外层**：`<header data-page-header className="sticky top-0 z-[var(--z-sticky)] flex h-[var(--header-h)] shrink-0 items-center gap-4 border-b border-line bg-panel px-6">`。

**元素**：
1. `<h1 className="text-16 font-semibold text-fg-1 truncate">{title}</h1>`。
2. `right` 放在右侧：`<div className="ml-auto flex items-center gap-3">`。

**数据 / 交互**：无。

**状态**：无。

**响应式**：< 800px 时左右内边距 `px-4`。

**文案**：由页面传入：总览 / 槽位 / 任务。浏览器标签页标题同步设成「{title} · fleet studio」（`useEffect` 设 `document.title`）。

## S3 提示条 `app/AppShell.tsx` 内的 `ShellBanners`

**外层**：内容区最上方（顶栏之上），`z-[var(--z-banner)]`，多条时纵向叠放。

**元素**：
1. 断线：`connection === "lost"` 且 `everOpened` 为 true 时显示 `<Banner kind="offline">连接已断开，正在重连</Banner>`；同时给内容区加 `opacity-60`（顶栏和提示条本身不变淡）。重连成功后消失。
2. 配置出错：`snapshot.configError` 不为 null 时显示 `<Banner kind="config">配置文件有错，正在使用上一份有效配置：{configError}</Banner>`，长文字单行省略，`title` 放全文。

**状态**：两条可以同时出现，断线在上。

**文案**：照上面逐字。

## S4 连不上服务 `app/ConnectionGate.tsx`

**签名**：`{ children: ReactNode }`。

**规则**：
- `everOpened` 为 false 且 `connection === "lost"`（第一次连就没连上）：用 `<div data-connection-gate className="flex flex-1 items-center justify-center p-6">` 替换 `children`，里面是 `EmptyState`：`icon={Unplug}`、`message="连不上 fleet 服务"`、`command="fleet daemon start"`、`action={{ label: "重试", onClick: 重新订阅快照 }}`。
- `everOpened` 为 false 且还在 `connecting`：渲染 `children`（各页自己画加载骨架）。
- 其余情况渲染 `children`。

**文案**：连不上 fleet 服务、fleet daemon start、重试。

## 本页交互检查会找的东西

| 位置 | 操作 | 断言 |
|---|---|---|
| `[data-nav-item]` | 数一数 | 3 个，依次 overview、slots、tasks |
| `[data-nav-item="slots"]` | 点击 | 地址变成 `#/slots`；该项 `aria-current="page"`；`[data-page-header] h1` 文字为「槽位」 |
| `#/w/wr8v2k` | 直接打开 | 地址变成 `#/tasks/wr8v2k`，任务那一项高亮 |
| `#/nope` | 直接打开 | 地址变成 `#/overview` |
| `[data-nav-toggle]` | 点击（1440 宽） | `[data-nav]` 的 `data-collapsed` 变成 `true`；再点变回 `false`；刷新后保持最后状态 |
| 800 宽 | 打开任一页 | `data-collapsed="true"`，`[data-nav-toggle]` 不可见 |
| `?demo=busy` | 打开 | `[data-nav-count]` 文字等于演示数据单测里 busy 场景的「进行中任务数」 |
| `?demo=offline` | 打开 | 出现 `[data-banner="offline"]`，文字「连接已断开，正在重连」 |
| `?demo=failure` | 打开 | 出现 `[data-banner="config"]` |
