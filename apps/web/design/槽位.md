# 槽位 `#/slots` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 这是**改版**：`features/slots/` 的行为全部照旧（本地覆盖顺序和启用状态、停用前确认、请求中禁用、断线时不可操作、占用格子键盘移动与提示卡、超出容量描红、重试斜纹、容量大于 24 画分段条），本页只改布局和外观。

本页节奏：工作区 `bg-panel` 上：40px 视图栏（右边公共排队）→（全部停用时一条黄色提示条）→ 通栏表格：没有外框卡片，表头和每行之间只有 1px 细线，像 Linear 的列表。
本页核心动作：看每个池的占用，停用 / 启用，上下移动调派活顺序。
本页最重要的区块：L3 槽位表格（含 L4 占用格子）。

## L1 公共排队 `features/slots/SharedQueuePill.tsx`

**外层**：`sharedQueued > 0` 时渲染 `<button data-shared-queue type="button" aria-label={`公共排队 ${n} 个，查看任务`} className="inline-flex h-7 items-center gap-1.5 rounded-md border border-line bg-card px-2 text-12 text-fg-2 shadow-card transition-colors hover:bg-raised">`；为 0 或快照没到时不渲染。

**元素**：`Clock` 14px `text-fg-3` → 「公共排队」（< 800 隐藏：`max-md:sr-only`）→ 数字 `font-mono text-fg-1`。

**交互**：点击 = `taskFilterStore.applyFromOverview({ status: "queued" })` 后 `navigate("/tasks/list")`（带着「排队中」进列表视图）。

**文案**：公共排队、公共排队 {n} 个，查看任务。

## L3 槽位表格 `features/slots/SlotsTable.tsx` + `SlotsTableRow.tsx`（最重要的区块）

**外层**：`<section data-slots-table className="min-w-0">` → `<div className="overflow-x-auto">` → 原生 `<table className="w-full min-w-[980px] table-fixed border-collapse text-13">`（窄屏在自己里面横向滚动）。

**表头**：一行 `h-8`；每格 `border-b border-line px-3 text-left text-12 font-medium text-fg-3`，第一格 `pl-4`、最后一格 `pr-4`，数字列 `text-right`。十列（宽度写在 `th` 上）：

| # | 表头 | 宽 | 对齐 |
|---|---|---|---|
| 1 | 优先级 | `w-16` | 左 |
| 2 | 渠道 · 模型 | 自适应 | 左 |
| 3 | 占用 | `w-[252px]` | 左 |
| 4 | 已用 | `w-20` | 右 |
| 5 | 点名排队 | `w-20` | 右 |
| 6 | 24 小时成功率 | `w-28` | 右 |
| 7 | 平均耗时 | `w-20` | 右 |
| 8 | 今日用量 | `w-20` | 右 |
| 9 | 启用 | `w-16` | 左 |
| 10 | 顺序 | `w-[76px] pr-4` | 左 |

**行**（`SlotsTableRow`）：`<tr data-pool-row={id} data-enabled={enabled ? "true" : "false"} className="h-14 border-b border-line transition-colors duration-[var(--dur-fast)] ease-[var(--ease)] hover:bg-hover">`，每格 `px-3 align-middle`（第一格 `pl-4`，最后一格 `pr-4`）。停用的行第 2～8 列整体 `text-fg-3`（完整类名映射，照旧）。各格：

1. 优先级：`font-mono text-13 text-fg-2`，显示顺序位置（1 起）。
2. 渠道 · 模型：第一行 `<span className="truncate font-mono text-13" title=…>{channel} · {modelName}</span>`，停用时后面跟 `<span data-disabled-tag className="ml-2 inline-flex h-5 shrink-0 items-center rounded-sm border border-line bg-raised px-1.5 text-12 text-fg-2">已停用</span>`；第二行 `truncate text-12 text-fg-3`：`{label}` + 空格 + `<span className="font-mono">{id}</span>`。
3. 占用：`<SlotMeter pool onOpenWorker />`（L4）。
4. 已用：`font-mono tabular-nums text-13`：`{running}`（超出容量时这个数 `text-status-failed`）+ ` / {capacity}`。
5. 点名排队：`font-mono tabular-nums text-13`，为 0 时 `text-fg-3` 的「—」。
6. 24 小时成功率：第一行 `font-mono tabular-nums text-13` 的百分比（没有结束的运行时 `text-fg-3`「—」）；有数据时第二行 `text-12 text-fg-3`「完成 {n} · 失败 {m}」，失败数 > 0 时「失败 {m}」这一段 `text-status-failed`。
7. 平均耗时：`<Duration ms={avgRunMs} />`（`text-13`），没有时「—」。
8. 今日用量：为 0 时 `text-fg-3`「—」；否则一个无边框按钮 `font-mono tabular-nums text-13 text-fg-1`，悬停提示 `<UsageBreakdown usage={usageToday} />`。
9. 启用：shadcn `Switch`，`data-pool-toggle={id}`、`aria-label={`启用 ${id}`}`；请求中 `opacity-60` 且禁用；断线时禁用（照旧）。
10. 顺序：`<div className="flex items-center gap-1">` 两个 `<Button variant="outline" size="icon-sm">`：上移（`ChevronUp`，`data-move-up={id}`，`aria-label={`${id} 上移一位`}`）、下移（`ChevronDown`，`data-move-down={id}`，`aria-label={`${id} 下移一位`}`）；首行的上移、末行的下移加 `invisible`（占位不进 Tab 序列，照旧）；有排序请求在飞或断线时两个都禁用。

**状态**：
- 快照没到：4 行骨架（每格一个 `Skeleton`：渠道 · 模型 `h-3.5 w-[140px]`，占用 `h-4 w-[180px]`，其余 `h-3.5 w-10`），行高同真行。
- 没有池：表格下方 `<EmptyState message="还没有配置模型池" />`。
- 改设置失败：sonner 提示（照旧，由 `queries.ts` 的钩子负责）；停用失败时错误写在确认框里（L5）。

**响应式**：表格最小 980px，窄于这个宽度在 `overflow-x-auto` 容器里横向滚动；页面本身不横向滚动。

**文案**：优先级、渠道 · 模型、占用、已用、点名排队、24 小时成功率、平均耗时、今日用量、启用、顺序、已停用、完成、失败、启用 {id}、{id} 上移一位、{id} 下移一位、还没有配置模型池。

## L4 占用格子 `features/slots/SlotMeter.tsx` + `SlotMeterCell.tsx` + `SlotMeterSegments.tsx`

行为全部照旧，只核对这几处外观：

- 离散格：每格 `h-4 w-2.5 rounded-[var(--r-slot)]`，格间 `gap-0.5`；被占的格底色 = 项目色（`style` 里 `backgroundColor: projectColorVar(…)`）；空格 `bg-meter-track ring-1 ring-inset ring-line-strong`；重试加 `hatch`；超出容量 `outline outline-1 -outline-offset-1 outline-status-failed`。
- 分段条（容量 > 24）：`h-4 w-[220px] rounded-[var(--r-slot)] bg-meter-track`，段间 `gap-0.5`。
- 容量为 0：虚线框 `h-4 w-[220px] rounded-[var(--r-slot)] border border-dashed border-line-strong` + `text-12 text-fg-3`「已暂停」。
- 停用的池整条 `opacity-40`。
- 提示卡（shadcn `Tooltip`）内容：第一行 `ColorDot` + 项目名（`text-12 font-medium text-fg-1`）；第二行标题 `truncate text-12 text-fg-1`；第三行 `text-12 text-fg-3`「{角色} · {已跑时长}」，重试时再加 `text-status-warning`「 · 正在重试」。
- 键盘：整组一个 Tab 位，左右方向键在格子间移动，回车 / 点击跳到 `#/tasks/<苦工编号>`（照旧）。
- 标记照旧：`data-slot-meter={id}`、`data-slot={runId}`、`data-retrying`、`data-segment`。

## L5 停用确认框 `features/slots/DisablePoolDialog.tsx`

行为照旧（请求中挡住 Esc 和取消；失败时留在框里显示原因）。外观：shadcn `AlertDialog`（外观由 ui 组件统一给：400px、圆角 6、`bg-overlay`、`shadow-overlay`）；标题 `text-14 font-medium`「停用 {id}？」；正文 `text-13 text-fg-2`（「还有 N 个在跑，会跑完；点名它的 M 个任务会一直排队到重新启用」，为 0 的半句不写）；错误 `text-12 text-status-failed`；按钮行右对齐：「取消」（`AlertDialogCancel`，描边款）、「停用」（`Button variant="destructive" data-confirm-disable`，请求中前面转一个 `LoaderCircle` 14px `animate-spin-slow`、两个按钮都禁用）。

**文案**：停用 {id}？、还有 {n} 个在跑，会跑完、点名它的 {n} 个任务会一直排队到重新启用、取消、停用。

## 本页交互检查会找的东西

演示数据的池顺序是 dsf、glmf、qwen27、luna；数字见 `src/api/demo/scenarios.test.ts`（dsf 18/20、排队 4、1 格重试；glmf 4/7；qwen27 0/5；luna 1/8；公共排队 3）。
