# 任务 `#/tasks`、`#/tasks/<编号>` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> T4、T5 是第一版苦工详情和时间线的迁移：**行为、结构、标记照 `design/工作区.md` 的 R6～R8**，本文件只写第二版的变化。

本页节奏：`bg-page` 上：细长的筛选条卡片 → （有已选条件时）一行小标签 → 主区：表格卡片（没打开详情时通栏；打开详情时左窄右宽两张卡片）。
本页核心动作：筛选、找到任务、点开看详情。
本页最重要的区块：T3 任务表格、T5 过程时间线。

## 页面组件 `pages/TasksPage.tsx`

```tsx
const { id } = useParams();            // 打开的任务编号，可能没有
<>
  <PageHeader title="任务" />
  <div data-page="tasks" className="flex min-h-0 flex-1 flex-col gap-4 p-6">
    <TaskFilterBar />                   {/* T1 */}
    <ActiveFilterChips />               {/* T2，没有已选条件时不渲染 */}
    <div className={id ? "grid min-h-0 flex-1 grid-cols-1 gap-4 lg:grid-cols-[minmax(0,36fr)_minmax(0,64fr)]" : "flex min-h-0 flex-1 flex-col"}>
      <TaskTable compact={id !== undefined} selectedId={id ?? null} />      {/* T3；< 1024 且打开详情时 hidden */}
      {id && <WorkerDetail id={id} onClose={() => navigate("/tasks")} />}   {/* T4、T5 */}
    </div>
  </div>
</>
```

- 打开详情且窗口 < 1024px：表格卡片加 `hidden lg:flex`（表格整个藏起来），详情占满（T4 顶部出现「返回」）。
- 页面主区不整体滚动：表格卡片和详情卡片各自 `min-h-0 overflow-y-auto`。
- `TaskTable` 的 `compact`、`selectedId` 两个参数是本页唯一允许区块接收的参数。

## T1 筛选条 `features/tasks/TaskFilterBar.tsx`

**外层**：`<section data-task-filters className="flex flex-wrap items-center gap-2 rounded-lg border border-line bg-panel px-4 py-3">`。

**元素**（从左到右，全部受控，值读写 `taskFilterStore`）：

| # | 控件 | 宽 | 选项 | 触发器显示 | 标记 |
|---|---|---|---|---|---|
| 1 | shadcn `Select` | 136px | 进行中（active）、排队中、工作中、重试中、已完成、失败、已取消、全部 | 「状态：{选中项}」 | `data-filter="status"` |
| 2 | shadcn `Select` | 168px | 「全部项目」+ `useProjects()` 的每一项（`ColorDot` + 名字） | 选中项的名字，或「全部项目」 | `data-filter="project"` |
| 3 | shadcn `Select` | 144px | 「全部池」+ `snapshot.pools` 的每一项（`font-mono` 编号 + `text-fg-3` 的显示名） | 池编号，或「全部池」 | `data-filter="pool"` |
| 4 | shadcn `Select` | 128px | 「全部角色」+ `snapshot.roles` 的每一项（中文名） | 角色中文名，或「全部角色」 | `data-filter="role"` |
| 5 | `RangePicker variant="select" name="tasks-range"` | 132px | 同总览 | 档位名或「09-01 ~ 09-25」 | `data-filter="range"` |
| 6 | 搜索框：shadcn `Input`，左侧 `Search` 14px 图标（绝对定位，`pl-8`），右侧有字时出现 `X` 清空按钮（`aria-label="清空搜索"`） | 240px，`ml-auto`（< 1280 时换到下一行、占满宽） | — | 占位「搜索标题」 | `data-filter="q"` |

每个下拉的「全部 X」项的值用空字符串表示「不筛」，写进仓库时变成 `undefined`。搜索框输入后 300 毫秒没有新输入才写进仓库（本地状态 + 定时器，卸载时清定时器）；按回车立即写；清空按钮立即写空串。

**数据**：`taskFilterStore`；项目列表 `useProjects()`（加载中时项目下拉只有「全部项目」一项，出错也一样）；池和角色来自快照。

**交互**：任何一项改变 → 仓库更新 → T3 的查询键变化 → 重新从第一页加载（TanStack Query 换键自动完成）。改筛选**不**关闭已打开的详情。

**状态**：快照还没到时池、角色下拉只有「全部 X」。

**响应式**：`flex-wrap`；< 1280 搜索框独占一行（`basis-full xl:basis-auto`）。

**文案**：状态：、进行中、排队中、工作中、重试中、已完成、失败、已取消、全部、全部项目、全部池、全部角色、搜索标题、清空搜索。

## T2 已选条件 `features/tasks/ActiveFilterChips.tsx`

**外层**：`activeFilterChips(filters, lookups)` 返回非空时渲染 `<div data-active-filters className="flex flex-wrap items-center gap-2">`，否则不渲染。

**元素**：
1. 每个条件一个小标签：`<span data-chip={key} className="inline-flex h-6 items-center gap-1 rounded-sm bg-brand-soft pl-2 pr-1 text-12 text-fg-1">{label}<button aria-label="去掉 {label}" className="rounded-sm p-0.5 text-fg-3 hover:text-fg-1"><X size={12} /></button></span>`。
2. 最后一个文字按钮「清除筛选」（`variant="link" size="sm"`，`text-brand`，标记 `data-clear-filters`）。

小标签的 `key` 和文字（由 `lib/taskFilters.ts` 的 `activeFilterChips` 给出，本路只管渲染）：

| key | 什么时候出现 | 文字 |
|---|---|---|
| `status` | 状态不是「进行中」 | 状态：{中文} |
| `project` | 选了项目 | 项目：{项目名} |
| `pool` | 选了池 | 池：{编号} |
| `role` | 选了角色 | 角色：{中文名} |
| `channel` | 从总览带来 | 渠道：{渠道名} |
| `model` | 从总览带来 | 模型：{模型名} |
| `range` | 时间不是「全部」 | 时间：{档位名或日期段} |
| `q` | 搜索词非空 | 搜索：{词}（超过 16 个字截断加「…」） |

**交互**：点小标签的 `X` → 该项回到默认（状态回到「进行中」，其余清空）；「清除筛选」→ `reset()`。

**文案**：去掉 {label}、清除筛选，以及上表。

## T3 任务表格 `features/tasks/TaskTable.tsx`（最重要的区块之一）

**签名**：`{ compact: boolean; selectedId: string | null }`。

**外层**：`<section data-task-table data-compact={compact ? "true" : "false"} className="flex min-h-0 min-w-0 flex-col overflow-hidden rounded-lg border border-line bg-panel">`，里面滚动容器 `<div data-task-scroll className="min-h-0 flex-1 overflow-auto">`，再里面 shadcn `Table`。

**完整模式**（`compact` 为 false）的列：

| # | 表头 | 宽 | 单元格 |
|---|---|---|---|
| 1 | 标题 | 最小 280px | `text-13 text-fg-1` 单行省略，`title` 放全文；下面一行 `font-mono text-11 text-fg-3` 苦工编号 |
| 2 | 项目 | 160px | `ColorDot`（项目色，从 `useProjects()` 或快照按 `projectKey` 找 `colorIndex`）+ 项目名（单行省略） |
| 3 | 角色 | 96px | `RoleChip label={roleLabel}` |
| 4 | 池 | 96px | `poolId` 有值：`font-mono text-13`；为 null：`text-12 text-fg-3`「公共排队」 |
| 5 | 状态 | 最小 180px | `StatusBadge size="sm" status retry queuePosition shared={poolId === null}`；失败时后面跟「 · {FAIL_REASON_LABELS[failReason]}」（`text-12 text-fg-3`，单行省略）；有回报结论 `verdict` 为 fail 时后面跟 `VerdictTag` |
| 6 | 用量 | 96px，右对齐 | `font-mono tabular-nums text-13`：`formatTokens(usage.totalTokens)`；为 0 时「—」。悬停（shadcn `Tooltip`）显示 `<UsageBreakdown usage={usage} />` |
| 7 | 耗时 | 96px，右对齐 | 工作中：`<Duration from={startedAt} />`（这次运行，实时走）；其余：`runMs > 0 ? <Duration ms={runMs} /> : "—"` |
| 8 | 开始时间 | 112px，右对齐 | `font-mono tabular-nums text-12 text-fg-2`：`formatClock(createdAt, now)` |

表头：`sticky top-0 z-[var(--z-sticky)] bg-panel`，`text-12 font-medium text-fg-3`。可排序的三列（用量 → `tokens`、耗时 → `runMs`、开始时间 → `createdAt`）的表头是按钮：文字 + 图标（当前排序列：降序 `ArrowDown`、升序 `ArrowUp`；非当前列：`ArrowUpDown` `text-fg-3`），`th` 上 `aria-sort` 取 `descending` / `ascending` / `none`，标记 `data-sort={键}`。点击：不是当前列 → 设为该列降序；是当前列 → 在降序和升序之间切换。

**紧凑模式**（`compact` 为 true）：只有一列，不显示表头。每行两层：上面 `StatusBadge size="sm"`（同上的参数），下面标题（`text-13 text-fg-1` 单行省略）；行内边距 `px-4 py-3`。

**行**：`<tr data-task-row={id} aria-selected={id === selectedId} tabIndex={0}>`；悬停 `bg-hover`；选中 `bg-selected` 并在第一格左侧画 2px `bg-brand` 竖条（`relative` + 伪元素或一个 `absolute inset-y-0 left-0 w-0.5 bg-brand` 的 span）。点击或回车 → `navigate("/tasks/" + id)`；上下方向键在行之间移动焦点。

**数据**：
- `useTasks(toTasksQuery(filters))` 的全部已加载页拼起来，再 `mergeLiveSummaries(items, snapshot.workers)`（进行中的行用快照里的新鲜数据）。
- `total` 取第一页的 `total`。

**滚动加载**：列表末尾放 `<div data-load-more className="h-px" />`，用 `IntersectionObserver`（`root` = `data-task-scroll` 那个容器，`rootMargin: "200px"`）；进入视野且 `hasNextPage && !isFetchingNextPage` 时 `fetchNextPage()`。加载下一页时末尾画 3 行骨架。已经没有下一页且有数据时，末尾一行 `py-3 text-center text-12 text-fg-3`「共 {total} 个」，标记 `data-task-total`。

**状态**：
- 第一页加载中：8 行骨架（完整模式每格一个 `Skeleton`，紧凑模式两条）。
- 出错：`ErrorState message={error.message} onRetry={refetch}`。
- 空：
  - 所有筛选都是默认值（状态「进行中」、其余空）：`EmptyState icon={Inbox} message="没有进行中的任务" action={{ label: "查看全部", onClick: () => set({ status: "all" }) }}`；
  - 状态为「全部」且其余都空：`EmptyState message="还没有任务" command='fleet run "任务"'`；
  - 其余：`EmptyState message="没有符合条件的任务" action={{ label: "清除筛选", onClick: reset }}`。
- 选中的任务不在当前列表里（被筛掉了）：不影响详情，表格里只是没有高亮行。

**响应式**：完整模式表格 `min-w-[960px]`，在滚动容器里横向滚动；紧凑模式不设最小宽度。

**文案**：标题、项目、角色、池、状态、用量、耗时、开始时间、公共排队、没有进行中的任务、查看全部、还没有任务、没有符合条件的任务、清除筛选、共 {n} 个。

## T4 详情面板 `features/worker/WorkerDetail.tsx`（任务详情路）

**签名**：`{ id: string; onClose(): void }`。

**来源**：第一版 `features/worker/` 整个目录的行为照 `design/工作区.md` R6（详情头与元信息）、R7（任务与回报）搬过来，改动只有下面这些：

1. **样式**：CSS Modules 全部换成 Tailwind 类名（第 2 章），删掉 `*.module.css`；第一版的共享组件换成第二版的：`ProjectDot` → `ColorDot` + `projectColorVar`；`Tip` → shadcn `Tooltip`；`Disclosure` → shadcn `Collapsible`（本目录里可以新建 `WorkerDisclosure.tsx` 包一层，保留原来的 `data-disclosure`、`data-open` 标记）；`FilterChips` → `SegmentedControl`（保留原来的 `data-filter` 标记：给每项再加 `data-filter={value}`）；`Skeleton` → shadcn `Skeleton`。
2. **外层**：`<section data-detail id="detail-scroll" className="min-h-0 min-w-0 overflow-y-auto rounded-lg border border-line bg-panel">`（`id="detail-scroll"` 是跟随滚动找容器用的，第一版就是这个名字）。
3. **打开 / 关闭**：挂载或 `id` 变化时 `workerStore.open(id)`，卸载时 `close()`。
4. **头部右侧**：`CopyButton text={id} label="复制编号" showText`（标记 `data-copy-id`）；再一个关闭按钮（`variant="ghost" size="icon"`，`X`，`aria-label="关闭详情"`，标记 `data-detail-close`，点了调 `onClose`）。窗口 < 1024px 时关闭按钮换成头部**左侧**的「返回」按钮（`ArrowLeft` + 「返回」，标记 `data-detail-back`，同样调 `onClose`）。
5. **元信息「池与模型」**：`poolId` 为 null 时显示「公共排队（还没分到池）」（`text-fg-3`）；否则「{poolId} · {model}」（等宽）。另加一格「渠道」：`channel ?? "—"`（等宽）。
6. **不存在**：`status === "notFound"` 时 `EmptyState message="没有这个任务"`（第二版任务记录永久保留，第一版的「已被清理」文案不再用）。

## 本页交互检查会找的东西

期望值来自演示数据单测。

| 位置 | 操作 | 断言 |
|---|---|---|
| `?demo=busy#/tasks` 的 `[data-task-row]` | 数一数 | 等于 busy 场景「进行中」任务数（不超过 50） |
| `[data-filter="status"]` | 选「全部」 | 行数变成 50（第一页），`[data-task-total]` 出现前继续滚到底能加载更多 |
| `[data-task-scroll]` | 滚到底，等 1 秒 | 行数大于 50 |
| `[data-sort="tokens"]` | 点击 | `aria-sort="descending"`；第一行的用量 ≥ 第二行 |
| `[data-filter="q"]` | 输入 busy 场景某个唯一标题里的一段，等 400 毫秒 | 只剩 1 行，`[data-chip="q"]` 出现 |
| `[data-clear-filters]` | 点击 | 小标签全部消失，状态回到「进行中」 |
| 第一个 `[data-task-row]` | 点击 | 地址 `#/tasks/<编号>`；`[data-task-table]` 的 `data-compact="true"`；`[data-detail]` 出现 |
| `[data-detail-close]` | 点击 | 地址 `#/tasks`，`data-compact="false"` |
| `#/tasks/wr8v2k` | 打开 | 时间线行数、筛选计数、回报段落与第一版交互检查一致（见 `design/工作区.md` 文末的表） |
| `[data-copy-id]` | 读文字 | 等于地址里的编号 |
| 800 宽打开 `#/tasks/wr8v2k` | 查 | 表格卡片不可见；`[data-detail-back]` 可见 |
