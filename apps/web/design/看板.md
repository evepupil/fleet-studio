# 任务 · 看板 `#/tasks` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 视图栏、筛选栏、显示弹层不归本路（列表路写，见 `design/任务列表.md`）；本路只写看板本体 `TaskBoard`。

本页节奏：工作区 `bg-panel` 近白 → 每一列是一条 `bg-column` 淡灰托盘（圆角 6）→ 托盘里是 `bg-card` 白卡片（1px `border-line`、圆角 6、`shadow-card`）；右侧收起组是几条同样淡灰的短条。四层底色就是设计提炼的「浅灰 → 近白 → 白」。
本页核心动作：扫一眼三列，点一张卡进详情；点右侧短条展开失败或已取消。
本页最重要的区块：T4 看板——全站门面，允许写得最长、视觉投入最大。

## T4 看板 `features/board/TaskBoard.tsx`（最重要的区块）

可以拆的子组件（只能放在 `features/board/`、以 `TaskBoard` 开头）：`TaskBoardColumn.tsx`（一列）、`TaskBoardCard.tsx`（一张卡）、`TaskBoardCardMeta.tsx`（卡片进度小片）、`TaskBoardEnded.tsx`（右侧收起组）、`TaskBoardSkeleton.tsx`（加载骨架）、`useTaskBoardKeys.ts`（方向键移动焦点）。

**签名**：`export function TaskBoard()`，无参数。

### 外层

```tsx
<div
  data-board
  className="flex h-full min-h-0 gap-2 overflow-x-auto overflow-y-hidden p-2 max-md:snap-x max-md:snap-mandatory"
  onKeyDown={handleArrowKeys}
>
  {layout.columns.map((status) => <TaskBoardColumn … />)}
  {layout.collapsed.length > 0 ? <TaskBoardEnded … /> : null}
</div>
```

- 整个看板在 `data-page-body`（高度已定）里占满高度；列各自纵向滚动；列放不下时整个看板在自己里面横向滚动（页面本身不横向滚动）。

### 数据

```ts
const snapshot = useSnapshotStore((s) => s.snapshot);
const { project, pool, role, channel, model, q } = useTaskFilterStore(); // 只取这几项
const reset = useTaskFilterStore((s) => s.reset);
const expanded = useBoardStore((s) => s.expanded);
const toggleExpanded = useBoardStore((s) => s.toggleExpanded);
const cardProps = useDisplayStore((s) => s.cardProps);

const all = snapshot?.workers ?? [];
const filtered = useMemo(() => filterBoardWorkers(all, { project, pool, role, channel, model, q }), [...]);
const columns = useMemo(() => groupBoardColumns(filtered), [filtered]);
const layout = boardLayout(expanded);
```

状态和时间范围对看板不起作用（`filterBoardWorkers` 不认它们）。列内顺序已经由 `groupBoardColumns` 排好，**不要再排**：排队中按排队位次、工作中最近开跑的在前、已结束三列最近结束的在前。

### 一列 `TaskBoardColumn`

参数 `{ status: RunStatus; items: WorkerSummary[]; collapsible: boolean; onCollapse(): void; cardProps: Record<CardProp, boolean> }`。

```tsx
<section
  data-board-column={status}
  data-count={items.length}
  aria-label={`${label} ${items.length} 个`}
  className="flex h-full min-h-0 min-w-[var(--board-col-min)] flex-1 basis-0 flex-col rounded-lg bg-column max-md:min-w-[280px] max-md:snap-start"
>
  <header className="flex h-9 shrink-0 items-center gap-2 pl-3 pr-1.5">
    <StatusIcon status={status} size={14} />
    <h2 className="truncate text-13 font-medium text-fg-1">{label}</h2>
    <span data-column-count className="text-13 text-fg-3">{items.length}</span>
    {collapsible ? (
      <Button variant="ghost" size="icon-sm" className="ml-auto" data-collapse-column={status}
        aria-label={`收起${label}`} title={`收起${label}`} onClick={onCollapse}>
        <ChevronsRight aria-hidden="true" />
      </Button>
    ) : null}
  </header>
  <div data-column-body className="flex min-h-0 flex-1 flex-col gap-2 overflow-y-auto px-2 pb-2">
    {items.map((worker) => <TaskBoardCard key={worker.id} worker={worker} props={cardProps} />)}
  </div>
</section>
```

- `label` = `STATUS_META[status].label`（排队中、工作中、已完成、失败、已取消）。
- 列里一张卡都没有时，列头照常显示「0」，列身空着（不写任何字）。
- 列宽：展开的列平分剩余宽度（`flex-1 basis-0`），最窄 248px；卡片等宽、高度随内容。

### 一张卡 `TaskBoardCard`（设计提炼的三层任务卡）

参数 `{ worker: WorkerSummary; props: Record<CardProp, boolean> }`。整张卡是 React Router 的 `<Link>`（语义是跳转，键盘回车、鼠标中键都自然可用）：

```tsx
<Link
  to={`/tasks/${worker.id}`}
  data-task-card={worker.id}
  data-status={worker.status}
  className="group flex w-full shrink-0 flex-col gap-1.5 rounded-lg border border-line bg-card p-3 text-left shadow-card transition-colors duration-[var(--dur-fast)] ease-[var(--ease)] hover:border-line-strong focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-brand"
>
```

从上到下三层：

1. **编号与负责人**（`props.id` 或 `props.pool` 至少一个为 true 才渲染这一行）：`<div className="flex h-4 min-w-0 items-center gap-2 text-12">`
   - 编号（`props.id`）：`<span data-card-id className="shrink-0 font-mono text-fg-3">{id}</span>`
   - 负责人 = 所在的池（`props.pool`）：`poolId` 有值时 `<span data-card-pool className="ml-auto min-w-0 truncate font-mono text-fg-2" title={model ?? poolId}>{poolId}</span>`；为 null 时 `<span data-card-pool className="ml-auto shrink-0 text-fg-3">公共排队</span>`。
2. **状态与标题**（总是渲染）：`<div className="flex min-w-0 items-start gap-2">`
   - `<StatusIcon status={status} retrying={retry !== null} size={14} label={statusLabel} className="mt-[1.5px]" />`，`statusLabel`：重试中写「重试中」，否则 `STATUS_META[status].label`。
   - 标题 `<p data-card-title title={title} className="line-clamp-2 min-w-0 flex-1 break-words text-13 text-fg-1">{title}</p>`（最多两行，超出省略；`title` 属性放全文）。
3. **进度与分类标签**（这一行里至少有一样东西才渲染）：`<div className="flex min-w-0 flex-wrap items-center gap-1">`，按这个顺序：
   - 进度小片（`props.meta` 且 `cardMeta(worker)` 不为 null）：`<TaskBoardCardMeta meta={…} />`，见下。
   - 回报不通过（`verdict === "fail"`，不受开关控制）：`<VerdictTag verdict="fail" />`。
   - 项目标签（`props.project`）：`<ProjectLabel projectKey={projectKey} />`。
   - 角色标签（`props.role`）：`<Label data-label="role">{roleLabel}</Label>`。

**进度小片 `TaskBoardCardMeta`**：参数 `{ meta: CardMeta }`（`CardMeta` 从 `lib/board.ts` 引）。外层 `<span data-card-meta={meta.kind} className={`inline-flex h-5 max-w-full min-w-0 items-center gap-1 rounded-sm border border-line bg-card px-1.5 text-12 ${TONE[meta.kind]}`}>`，`TONE` 是完整类名映射：

| kind | `TONE` | 内容 |
|---|---|---|
| `queue` | `text-fg-2` | `meta.text`（「排队第 4 位」「公共排队第 3 位」） |
| `elapsed` | `text-fg-2` | `Clock` 12px `text-fg-3` + `<Duration from={meta.from} />`（每秒走） |
| `retry` | `text-status-warning` | `RotateCw` 12px + `meta.text`（「重试 3/8」） |
| `duration` | `text-fg-2` | `Clock` 12px `text-fg-3` + `<Duration ms={meta.ms} />` |
| `failure` | `text-status-failed` | `<span className="truncate">{meta.text}</span>`（「运行超时」等） |

图标都 `aria-hidden="true"`、`size-3 shrink-0`。

**卡片的状态**：
- 悬停：描边从 `border-line` 变成 `border-line-strong`，底色不变。
- 键盘聚焦：2px 强调色焦点环（`focus-visible`）。
- 长标题：两行省略；长项目名：标签内单行省略（`Label` 自带）；长池名：右上角单行省略。
- 数据缺失：`cardMeta` 为 null 时不画小片；第三层整行都没有东西时整行不渲染。

### 右侧收起组 `TaskBoardEnded`（设计提炼的「已结束状态收成一组短行」）

参数 `{ statuses: CollapsibleColumn[]; counts: Record<CollapsibleColumn, number>; onExpand(status: CollapsibleColumn): void }`。

```tsx
<aside data-ended-group aria-label="收起的状态" className="flex w-[var(--ended-col-w)] shrink-0 flex-col gap-2 max-md:snap-start">
  {statuses.map((status) => (
    <button
      type="button"
      key={status}
      data-ended-row={status}
      data-count={counts[status]}
      aria-label={`展开${label}，${counts[status]} 个`}
      className="flex h-9 w-full items-center gap-2 rounded-lg bg-column px-3 text-left transition-colors duration-[var(--dur-fast)] ease-[var(--ease)] hover:bg-selected"
      onClick={() => onExpand(status)}
    >
      <StatusIcon status={status} size={14} />
      <span className="min-w-0 truncate text-13 font-medium text-fg-1">{label}</span>
      <span data-ended-count className={COUNT_TONE}>{counts[status]}</span>
    </button>
  ))}
</aside>
```

- `COUNT_TONE`：失败且数量 > 0 时 `ml-auto text-13 font-medium text-status-failed`（失败数标红）；其余 `ml-auto text-13 text-fg-3`。写成完整类名映射。
- 点一条：`toggleExpanded(status)`，这一状态变成一列插在「已完成」后面（固定顺序：失败在已取消前），短条随之消失；两条都展开后整组不渲染。展开的列头右边有「收起」按钮（见上），点了回到短条。展开状态由 `boardStore` 存进本地存储，刷新后保持。
- 收起组顶部对齐（不拉伸），短条之间 8px。

### 交互

- 点卡片：跳到 `#/tasks/<编号>`（详情页）。
- 方向键（`useTaskBoardKeys`，挂在 `data-board` 的 `onKeyDown` 上，只在焦点在某张 `[data-task-card]` 上时处理，处理了就 `preventDefault()`）：
  - ↓ / ↑：同一列下一张 / 上一张卡（到头不动）。
  - → / ←：相邻的下一列 / 上一列里**同一序号**的卡（那一列没那么多卡就取最后一张；那一列是空的就继续往后找下一个有卡的列；找不到不动）。
  - 找列和卡都从 DOM 取：`board.querySelectorAll("[data-board-column]")`、`column.querySelectorAll("[data-task-card]")`，移动后 `focus()` 并 `scrollIntoView({ block: "nearest", inline: "nearest" })`。
- 回车：卡片本身是链接，浏览器自带。

### 状态

- **快照还没到**（`snapshot === null`）：`TaskBoardSkeleton`：同样的外层里画 3 列列壳（`bg-column` 托盘，列头里一个 `Skeleton h-3.5 w-16`），每列 3 个 `Skeleton h-[88px] w-full rounded-lg`；右侧收起组位置画 2 个 `Skeleton h-9 w-full rounded-lg`。外层仍带 `data-board`，另加 `data-loading="true"`。
- **一个任务都没有**（快照到了且 `snapshot.workers.length === 0`）：外层换成 `<div data-board data-empty-board className="flex h-full items-center justify-center p-6">`，里面 `<EmptyState icon={Inbox} message="还没有任务" command={'fleet run "任务"'} />`。
- **筛选后一个都不剩**（有任务，但 `filtered.length === 0`）：同样的居中外层（`data-empty-board`），`<EmptyState message="没有符合条件的任务" action={{ label: "清除筛选", onClick: reset }} />`。
- **断线**：数据停在最后一次快照，页面整体变淡由骨架负责，看板不另外提示。
- **某列为空**：只有列头，列身空白。

### 响应式

| 宽度 | 结构 |
|---|---|
| ≥ 1280 | 三列平分 + 右侧收起组 200px，一屏放下，不横向滚动 |
| 1024–1279 | 列宽到 248px 下限后看板内部横向滚动 |
| 800–1023 | 侧栏变抽屉，工作区变宽；同上 |
| < 800 | 每列 280px，看板横向滚动并按列吸附（`snap-x snap-mandatory` + 列 `snap-start`），一次看一列多一点 |

### 文案

排队中、工作中、已完成、失败、已取消、收起{状态}、展开{状态}，{n} 个、收起的状态、公共排队、排队第 N 位、公共排队第 N 位、重试 N/M、不通过、还没有任务、没有符合条件的任务、清除筛选、fleet run "任务"。
