# 任务 · 详情 `#/tasks/<编号>` —— 逐区块规格（DESIGN.md 第 5 章之一）

> 先读完 `DESIGN.md` 全文再读本文件。令牌、共享组件签名、文案原则、写入边界都在 DESIGN.md，这里不重复。
> 规格里写了的元素一个都不能少；没写的细节按同一套令牌补齐，不要自己加区块、加文案。
> 凡是写了 `data-*` 属性、`id`、`aria-label` 的地方，交互检查会用到，**名字和取值不能改**。
> 这是**改版**：`features/worker/` 下的详情头、元信息、回报、任务书、时间线已经实现并验收过，行为一律照旧（订阅与退订、跟随滚动、「回到最新」、1000 行上限、多次运行分隔、8 行折叠、工具展开、筛选计数），本页只改**布局和外观**：从「表格右边的卡片」改成独占工作区的详情页，左边正文、右边属性栏（Linear 的任务页那样）。

本页节奏：工作区 `bg-panel` 上：40px 视图栏（面包屑）→ 下面左右两栏：左栏正文在近白底上，内容最宽 800px 居中；右栏属性栏 280px，左边一条 1px 细线，同样近白底。回报、任务书正文是白卡片（`bg-card`）或浅灰块（`bg-raised`）。
本页核心动作：看标题和状态、读回报、看时间线。
本页最重要的区块：D3 时间线（停留最久），其次 D2 回报。

可以新建和改的文件：`features/worker/**`（现有文件全部可改，新增文件以现有组件名或 `TaskProperties` 开头），`pages/TaskDetailPage.tsx`。

## D1 视图栏与页面 `pages/TaskDetailPage.tsx`

**签名**：`export function TaskDetailPage()`。

```tsx
const { id = "" } = useParams();
const navigate = useNavigate();
const location = useLocation();
const lastTasksView = useViewStore((s) => s.lastTasksView);
// 站内跳进来的就退回上一页（可能是看板、列表、槽位格子、搜索）；直接打开链接的退回任务页
const goBack = useCallback(() => {
  if (location.key !== "default") navigate(-1);
  else navigate(tasksPath(lastTasksView));
}, [location.key, navigate, lastTasksView]);

<>
  <ViewBar
    documentTitle={`任务 ${id}`}
    title={
      <>
        <button type="button" data-detail-back onClick={goBack}
          className="rounded-sm text-fg-2 transition-colors hover:text-fg-1">任务</button>
        <ChevronRight aria-hidden="true" className="size-3.5 shrink-0 text-fg-3" />
        <span data-detail-crumb className="truncate font-mono text-fg-1">{id}</span>
      </>
    }
    right={<span data-copy-id><CopyButton text={id} label="复制编号" /></span>}
  />
  <div data-page-body className="flex min-h-0 flex-1">
    <WorkerDetail id={id} onBack={goBack} />
  </div>
</>
```

- **Esc 返回**：在 `window` 上监听 `keydown`；`key === "Escape"`、事件没被别人 `preventDefault`、页面上没有打开的弹层（`document.querySelector('[role="dialog"], [role="menu"], [data-radix-popper-content-wrapper]') === null`）、焦点不在输入框或可编辑区域时，调 `goBack()`。卸载时移除监听。

**文案**：任务、复制编号。

## D2 正文 `features/worker/WorkerDetail.tsx`

**签名**：`export function WorkerDetail({ id, onBack }: { id: string; onBack(): void })`。挂载或 `id` 变化时 `workerStore.open(id)`，卸载时 `close()`（照旧）。

**外层**：`<div data-detail className="flex min-h-0 min-w-0 flex-1">`，里面左右两栏：


### 详情头 `features/worker/DetailHeader.tsx`

参数改成 `{ detail: WorkerDetail }`（关闭和返回按钮挪到视图栏了，这里删掉）。

1. 标题：`<h1 data-detail-title title={title} className="line-clamp-3 break-words text-16 font-medium text-fg-1">{title}</h1>`。
2. 状态行：`<div className="mt-2 flex flex-wrap items-center gap-x-3 gap-y-1">`
   - `<StatusBadge size="md" status retry queuePosition shared={poolId === null} />`
   - 耗时 `<span className="font-mono text-12 tabular-nums {queued ? "text-fg-3" : "text-fg-2"}"><Duration from={startedAt ?? queuedAt} to={进行中 ? null : endedAt} /></span>`（规则照旧：工作中实时走；排队中从排队时刻起算、颜色更淡；结束的定格）。颜色两种写成完整类名映射。
   - 有回报结论时 `<VerdictTag verdict={verdict} />`。
   - `runSeq > 1` 时 `<span className="text-12 text-fg-3">第 {runSeq} 次运行</span>`。
3. 失败说明（照旧，只换外观）：失败或已取消且有错误信息时 `<div data-failure title={errorMessage} className="mt-3 rounded-md px-3 py-2 text-12 {failed ? "bg-status-failed-soft" : "bg-raised"}">`：有失败原因时先写 `<span className="font-medium text-fg-1">{FAIL_REASON_LABELS[failReason]}：</span>`，再写 `<span className="line-clamp-4 whitespace-pre-wrap break-words text-fg-2">{errorMessage}</span>`。

### 回报 `features/worker/ReportCard.tsx`

逻辑照旧（按段落画、`SELF_REPORT` / `VERDICT` 段首词拆出结论、按行数折叠「展开全部 / 收起」、解析失败时整段原文）。外观：

### 任务书 `features/worker/TaskSection.tsx` + `WorkerDisclosure.tsx`

- 折叠标题从「任务」改成「任务书」；默认展开规则照旧（排队中展开，其余折叠）；标题右侧摘要照旧（第一行有信息量的文字）。
- `WorkerDisclosure` 外观：触发行 `flex h-8 w-full items-center gap-2 rounded-md px-1 text-left transition-colors hover:bg-hover`；箭头 `ChevronRight` 14px `text-fg-3`，展开时转 90°；标题 `text-13 font-medium text-fg-1`；摘要 `min-w-0 max-w-[50%] truncate text-right text-12 text-fg-3`。`data-disclosure`、`data-open` 标记照旧。
- 正文块：`mt-2 max-h-[360px] overflow-y-auto rounded-lg border border-line bg-raised px-3 py-2.5 text-13 whitespace-pre-wrap break-words text-fg-1`。
- 外层 `<section data-task className="mt-6">`。

### 状态

- **加载中**（`status !== "ready"` 或 `detail === null`）：`data-detail` 外层照样左右两栏；左栏里 `DetailLoadingSkeleton`：标题两条（`h-5 w-3/5`、`h-4 w-2/5`）→ `mt-6` 回报块（`h-32 w-full rounded-lg`）→ `mt-6` 时间线 5 条（`h-5 w-full`）；宽屏右栏里 8 行属性骨架（每行 `h-4 w-full`，间距 `gap-4`）。
- **找不到**（`notFound`）：`<div data-detail className="flex flex-1 items-center justify-center p-6"><EmptyState message="没有这个任务" action={{ label: "回到任务", onClick: onBack }} /></div>`。
- **出错**：同样居中，`<EmptyState message={"加载失败：" + error} action={{ label: "重试", onClick: () => workerStore.open(id) }} />`。

**文案**：任务书、回报、第 N 次运行、展开全部、收起、无、没有这个任务、回到任务、加载失败：、重试。

## D4 属性栏 `features/worker/TaskProperties.tsx`

**签名**：`export function TaskProperties({ detail, variant }: { detail: WorkerDetail; variant: "aside" | "inline" })`。旧的 `MetaGrid.tsx` 删掉，它的内容搬到这里。

**外层**：
- `aside`：`<dl data-properties className="grid grid-cols-[64px_minmax(0,1fr)] gap-x-3 gap-y-3.5">`，每项是相邻的 `<dt>` + `<dd>`。
- `inline`：`<dl data-properties className="mt-4 grid grid-cols-1 gap-x-6 gap-y-3 rounded-lg border border-line bg-card p-4 shadow-card md:grid-cols-2">`，每项包一层 `<div className="grid min-w-0 grid-cols-[64px_minmax(0,1fr)] gap-x-3">`。

`dt`：`pt-px text-12 text-fg-3`；`dd`：`min-w-0 text-13 text-fg-1`。每项的 `dd` 带 `data-prop={键}`。十项，按这个顺序：

| 键 | 标签 | 值 |
|---|---|---|
| `status` | 状态 | `StatusBadge size="md"`（参数同详情头） |
| `duration` | 耗时 | 同详情头的耗时（`font-mono text-13`） |
| `project` | 项目 | 第一行 `ColorDot`（项目色）+ 项目名（单行省略）；第二行 `<MonoPath path={项目路径} max={32} />`（`text-12 text-fg-3`）。项目名、路径、色位：先按 `projectKey` 在快照 `projects` 里找，找不到退回详情自带的 `projectPath`，名字取路径最后一段、色位 0（照搬现在 `MetaGrid` 的做法） |
| `role` | 角色 | `roleLabel`；第二行 `font-mono text-12 text-fg-3` 的 `role` |
| `pool` | 池 | `poolId` 有值：`font-mono` 池编号；第二行 `font-mono text-12 text-fg-3 truncate` 的 `model`。为 null：`text-fg-3`「公共排队」。第三行 `text-12 text-fg-3`：`{runtime}`，有思考档位再加「 · 思考 {thinking}」 |
| `channel` | 渠道 | `font-mono` 的 `channel`，为 null 写「—」 |
| `runs` | 运行 | 「第 {runSeq} 次」；有 `sessionRef` 时第二行 `font-mono text-12 text-fg-3 truncate` |
| `usage` | 用量 | `<span className="font-mono tabular-nums">{formatTokens(totalTokens)}</span> tokens`，有费用再加「 · {formatCost}」；第二行 `text-12 text-fg-3` 的 `<UsageBreakdown usage={usage} />`（整项换行，数字不截断） |
| `cwd` | 目录 | `<MonoPath path={cwd} max={32} />`，`font-mono text-12` |
| `created` | 创建 | `font-mono text-12 text-fg-2` 的 `formatClock(createdAt, now)` |

**状态**：值缺失一律写「—」（`text-fg-3`）；长值单行省略，`title` 放全文。

**文案**：状态、耗时、项目、角色、池、渠道、运行、用量、目录、创建、公共排队、第 N 次、tokens、思考。
